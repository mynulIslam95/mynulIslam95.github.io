Python from scratch, then AI

Fourteen written chapters. Read the rule, trace the examples and practice before opening the answer. Start with your first .py file, learn the Python foundations and then explore AI concepts. Finish with three programs you can run and explain.

How to study

Read → trace → practice → build. Each chapter has four checked questions and one written task with a hint and commented answer. Additional independent exercises follow each original lesson. You can learn from the written pages without watching the video.

Progress and drafts save in this browser. Written code is for self-review; this site does not run Python. Use Python locally or a notebook to verify your programs.

Ch01 · Open

Your first Python program

A program is a set of instructions. Python executes the statements at the top level of a file in order. You write a .py file, save it and ask the Python interpreter to run it. A notebook uses the same language but keeps results between cell runs.

Ch02 · Open

Variables and numeric types

A variable is a name referring to a Python object. Assignment binds or rebinds that name. It does not create a permanent box restricted to one type. Start with int for whole numbers, float for approximate decimal values and bool for True or False.

Reading · 4 checks · writing task

Ch03 · Open

Strings, slicing and casting

A string is an immutable sequence of Unicode characters. Indexing retrieves one character. Slicing builds a new string. This is useful for cleaning user input, extracting a filename or preparing text for an AI model.

Reading · 4 checks · writing task

Ch04 · Open

Operators and formatted output

Operators combine values, compare objects or update names. Before using a long expression, identify the operands and predict the result type. Parentheses make your intention easier to read.

Reading · 4 checks · writing task

Ch05 · Open

Decisions with if, elif and else

A conditional selects a block of instructions. The condition is evaluated first. Python then executes the first matching branch and skips the other branches of that same if statement.

Reading · 4 checks · writing task

Ch06 · Open

Loops and control flow

A loop repeats a block. A for loop takes values from an iterable. A while loop repeats while a condition remains truthy. You need both when processing files, records or batches of training data.

Reading · 4 checks · writing task

Ch07 · Open

Lists, copying and comprehensions

A list is an ordered mutable collection. It is useful for storing rows, predictions or a sequence of tasks. A list can contain different types, but a consistent structure makes real programs easier to maintain.

Reading · 4 checks · writing task

Ch08 · Open

Tuples and sets

Choose a collection based on what you need to do. A tuple is an ordered immutable sequence, often used for a fixed record. A set stores unique hashable elements and is useful for deduplicating data and checking membership.

Reading · 4 checks · writing task

Ch09 · Open

Dictionaries and text cleaning

A dictionary maps unique hashable keys to values. Use it for structured records, lookup tables and frequency counters. String methods help turn messy input into consistent dictionary keys.

Reading · 4 checks · writing task

Ch10 · Open

Functions, arguments and scope

A function packages reusable work behind a name. Parameters are local names that receive arguments. Calling a function starts its body; defining a function does not run that body.

Reading · 4 checks · writing task

Ch11 · Open

Functions as values, lambda and map

A function is an object. You can store it in a variable, pass it into another function or return it. This is how callback functions and configurable data transformations work.

Reading · 4 checks · writing task

Ch12 · Open

Exceptions and reliable input

An exception signals that a normal operation could not finish. Handling an expected error lets a program provide a useful response. Unexpected errors should remain visible so you can fix the cause.

Reading · 4 checks · writing task

Ch13 · Open

Classes and objects

A class defines the behavior and structure of a kind of object. An instance is one particular object created from that class. Use classes when data and the operations on it belong together.

Ch14 · Open

AI concepts from prompts to training

Python is the programming foundation. AI vocabulary helps you understand what you are building. Read the terms below, then practice distinguishing model training, inference and retrieval. This chapter explains concepts; it does not train a large language model.

Apply what you learned

Three projects, then GitHub

P1 · easy

Expense tracker

A command-line app that saves expenses between runs. Practice functions, dictionaries, JSON, validation and file errors.

P2 · medium

Search your study notes

Build a lexical document retriever using TF-IDF weighted word overlap. This is a retrieval building block for a future RAG app, without an LLM or embedding model.

P3 · hard

Train a text classifier

Train an actual small machine learning model from labeled text using multinomial naive Bayes. Implement training and inference with the standard library. The included dataset is deliberately tiny.
