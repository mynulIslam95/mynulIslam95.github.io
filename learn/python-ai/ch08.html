Tuples and sets

Choose a collection based on what you need to do. A tuple is an ordered immutable sequence, often used for a fixed record. A set stores unique hashable elements and is useful for deduplicating data and checking membership.

ReadingPractice sessionSave reading progress
The rule

A one-item tuple needs a trailing comma: (5,). {} creates an empty dictionary; set() creates an empty set. Set order is not a contract, so sort a set before displaying predictable output. Intersection keeps shared elements; union keeps elements from either set.

Worked example

point = (3, 4)
x, y = point  # Unpack two values into two names.
a = {"python", "sql"}
b = {"python", "linux"}
print(sorted(a & b))
print(len(a | b))
Trace every line

Unpacking binds x to 3 and y to 4. Only python appears in both sets, so the first output is ['python']. The union has python, sql and linux, so its length is 3. Sorting is only for stable display.
