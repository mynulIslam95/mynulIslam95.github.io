Exceptions and reliable input

An exception signals that a normal operation could not finish. Handling an expected error lets a program provide a useful response. Unexpected errors should remain visible so you can fix the cause.

ReadingPractice sessionSave reading progress
The rule

Put the risky operation in try. Catch a specific exception such as ValueError. else runs if try completed without an exception. finally runs when leaving the statement, including during most exception propagation. Avoid except: pass because it hides useful information.

Worked example

text = "twelve"
try:
    age = int(text)
except ValueError:
    print("Please enter a whole number.")
else:
    print(age + 1)
finally:
    print("Finished checking.")
Trace every line

int("twelve") raises ValueError. Assignment to age does not finish. The matching handler prints the request for a whole number. else is skipped. finally prints Finished checking. The program continues after the try statement.

1. Types of Errors

Errors in Python can be categorized into two major types:

  1. Syntax Errors
  2. Exceptions
a) Syntax Errors
  • Syntax errors, also known as parsing errors, occur when the parser detects a syntactic error.
  • These errors are caused when the Python interpreter fails to understand a line of code due to incorrect syntax.
  • These are detected before the program is executed.
  • Common causes include missing colons, incorrect indentation, etc.
### Example of a Syntax Error
if True
    print("Hello World")  # This will raise a SyntaxError because a colon (:) is missing after 'if True'
b) Exceptions
  • Exceptions occur when a syntactically correct code results in an error during execution.
  • Unlike syntax errors, exceptions are detected while the program is running.
  • Common examples include division by zero, accessing a file that does not exist, etc.
### Example of an Exception
num = 10
denom = 0
result = num / denom  # This will raise a ZeroDivisionError because division by zero is not allowed

2. Ways to Handle Exceptions in Python

Python provides a way to handle exceptions using try, except, else, and finally blocks.

a) Try
  • The try block contains the code that might throw an exception.
  • If an exception occurs in this block, it is passed to the except block for handling.
### Example of try block
try:
    print(5 / 0)  # This code might throw an exception
except ZeroDivisionError:
    print("Cannot divide by zero!")
b) Except
  • The except block is used to catch and handle exceptions that occur in the try block.
  • You can have multiple except blocks for different types of exceptions.
  • If an exception occurs, the except block executes.
### Example of multiple except blocks
try:
    number = int("xyz")  # This will raise a ValueError
except ValueError:
    print("Invalid value. Please enter a valid number.")
except TypeError:
    print("Type error occurred")
c) Else
  • The else block is executed if the try block does not raise an exception.
  • It is a good place to put code that should only run if no exceptions were raised.
### Example of else block
try:
    result = 10 / 2
except ZeroDivisionError:
    print("Cannot divide by zero!")
else:
    print(f"The result is {result}")
d) Finally
  • The finally block is always executed, whether an exception is raised or not.
  • It is often used for cleanup actions, like closing files or releasing resources.
### Example of finally block
try:
    file = open('nonexistent_file.txt', 'r')
except FileNotFoundError:
    print("File not found.")
finally:
    print("Executing the cleanup process.")

3. Raising an Error

  • Python allows you to manually raise exceptions using the raise keyword.
  • This is useful when you want to enforce certain conditions in your program.
### Example of raising an error
def check_age(age):
    if age < 18:
        raise ValueError("Age must be 18 or above.")
    return "Access granted"

### This will raise a ValueError
check_age(16)

4. Defining a Custom Error

  • You can define your own custom exceptions by creating a new class that inherits from Exception.
  • This allows you to create meaningful error messages specific to your application's needs.
### Example of defining a custom error
class InsufficientBalanceError(Exception):
    pass

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientBalanceError("You don't have enough funds!")
    return balance - amount

### This will raise an InsufficientBalanceError
withdraw(500, 600)

Python Exceptions Overview

This notebook explains common Python exceptions with examples. You can refer to the examples to quickly understand how each exception works.

ArithmeticError

This exception is raised when an error occurs in numeric calculations.

try:
    x = 1 / 0  # Division by zero
except ArithmeticError as e:
    print(f"ArithmeticError: {e}")

AssertionError

Raised when an assert statement fails.

try:
    assert 5 > 10, 'The value is not greater than 10'
except AssertionError as e:
    print(f"AssertionError: {e}")

AttributeError

Raised when an attribute reference or assignment fails.

try:
    None.lower()
except AttributeError as e:
    print(f"AttributeError: {e}")

Exception

Base class for all exceptions.

try:
    raise Exception('An unexpected error occurred.')
except Exception as e:
    print(e)

EOFError

Raised when the input() method hits an 'end of file' condition (EOF).

try:
    input()
except EOFError as e:
    print(f"EOFError: {e}")

FloatingPointError

Raised when a floating point calculation fails.

import math
try:
    math.exp(1000)
except FloatingPointError as e:
    print(f"FloatingPointError: {e}")

GeneratorExit

Raised when a generator is closed (with the close() method).

def my_gen():
    yield 1
    yield 2
    yield 3

gen = my_gen()
next(gen)
next(gen)
gen.close()
try:
    next(gen)
except GeneratorExit as e:
    print(f"GeneratorExit: {e}")

ImportError

Raised when an imported module does not exist.

try:
    import non_existent_module
except ImportError as e:
    print(f"ImportError: {e}")

IndentationError

Raised when indentation is not correct.

try:
    if True:
    print("Indented correctly")  # This line should be indented
except IndentationError as e:
    print(f"IndentationError: {e}")

IndexError

Raised when an index of a sequence does not exist.

try:
    my_list = [1, 2, 3]
    print(my_list[5])
except IndexError as e:
    print(f"IndexError: {e}")

KeyError

Raised when a key does not exist in a dictionary.

try:
    my_dict = {'a': 1, 'b': 2}
    print(my_dict['non_existent_key'])
except KeyError as e:
    print(f"KeyError: {e}")

KeyboardInterrupt

Raised when the user presses Ctrl+c, Ctrl+z, or Delete.

try:
    while True:
        pass  # Press Ctrl+C to raise the KeyboardInterrupt
except KeyboardInterrupt:
    print("KeyboardInterrupt: Process was interrupted.")

LookupError

Raised when errors raised can't be found.

try:
    raise LookupError('Unresolved lookup error.')
except LookupError as e:
    print(f"LookupError: {e}")

MemoryError

Raised when a program runs out of memory.

try:
    a = [1] * (10**10)  # Trying to allocate too much memory
except MemoryError as e:
    print(f"MemoryError: {e}")

NameError

Raised when a variable does not exist.

try:
    print(undefined_variable)
except NameError as e:
    print(f"NameError: {e}")

NotImplementedError

Raised when an abstract method requires an inherited class to override the method.

class BaseClass:
    def method(self):
        raise NotImplementedError('Subclass must implement this method.')

class SubClass(BaseClass):
    pass

try:
    obj = SubClass()
    obj.method()
except NotImplementedError as e:
    print(f"NotImplementedError: {e}")

OSError

Raised when a system-related operation causes an error.

try:
    open('non_existent_file.txt', 'r')
except OSError as e:
    print(f"OSError: {e}")

### Define custom exceptions
class InvalidAgeError(Exception):
    """Exception raised for invalid age."""
    def __init__(self, age):
        self.age = age
        super().__init__(f"Invalid age: {age}. Age must be a positive integer.")


class InvalidEmailError(Exception):
    """Exception raised for invalid email format."""
    def __init__(self, email):
        self.email = email
        super().__init__(f"Invalid email format: {email}. Email must be in the format 'username@example.com'.")



### Define the Person class
class Person:
    def __init__(self, name, age, email):
        self.name = name
        # Validate age

        
        if age <= 0:
            raise InvalidAgeError(age)
        self.age = age
        # Validate email format
        if "@" not in email or "." not in email:
            raise InvalidEmailError(email)
        self.email = email


### Example usage
try:
    # Trying to create a person with invalid age
    person1 = Person("Alice", -25, "alice@example.com")
except InvalidAgeError as e:
    print(e)


try:
    # Trying to create a person with invalid email format
    person2 = Person("Bob", 30, "bobexample.com")
except InvalidEmailError as e:
    print(e)
