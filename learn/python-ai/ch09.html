Dictionaries and text cleaning

A dictionary maps unique hashable keys to values. Use it for structured records, lookup tables and frequency counters. String methods help turn messy input into consistent dictionary keys.

ReadingPractice sessionSave reading progress
The rule

record[key] raises KeyError if a key is missing. record.get(key, default) returns a fallback. Iterating a dictionary yields keys; .items() yields key-value pairs. strip removes characters from the ends and lower returns lowercase text. Strings are immutable, so keep the returned result.

Worked example

words = " Python SQL python ".strip().lower().split()
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1
print(counts["python"])
print(counts.get("java", 0))
Trace every line

Cleaning gives the words python, sql and python. The first occurrence starts from zero and adds one. The second python increments the existing count to 2. Looking up missing java with get returns 0 without adding a new key.
