Classes and objects

A class defines the behavior and structure of a kind of object. An instance is one particular object created from that class. Use classes when data and the operations on it belong together.

ReadingPractice sessionSave reading progress
The rule

self refers to the instance receiving a method call. __init__ initializes instance state. Attributes such as self.balance belong to that instance. Class attributes are shared through the class, so do not use a mutable class attribute for data that should be separate for every instance. Inheritance reuses behavior; composition stores another object as part of an object.

Worked example

class Counter:
    def __init__(self, start=0):
        self.value = start

    def increment(self):
        self.value += 1
        return self.value

a = Counter()
b = Counter(10)
print(a.increment())
print(b.value)
Trace every line

Creating a calls __init__ with start=0. Creating b uses start=10. increment changes only a.value and returns 1. b.value is still 10 because the two instances have separate state.

Understanding Inheritance in Python

Inheritance is a fundamental concept in object-oriented programming where one class (child or derived class) inherits attributes and methods from another class (parent or base class). This allows for code reuse and establishes a relationship between classes.

1. Single Inheritance

In single inheritance, a child class inherits from a single parent class. This is the simplest form of inheritance.

### Single Inheritance Example

class Grandfather:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
    def show_details(self):
        return f'Name: {self.name}, Age: {self.age}'
        
    def speak(self):
        return 'Grandfather speaks wisely.'

class Father(Grandfather):
    def __init__(self, name, age, occupation):
        super().__init__(name, age)
        self.occupation = occupation
        
    def show_occupation(self):
        return f'Occupation: {self.occupation}'
    
    def speak(self):
        return 'Father speaks carefully.'

### Creating an object of the Father class
father_obj = Father('John', 50, 'Engineer')
father_obj.show_details()
father_obj.show_occupation()
father_obj.speak()

4. Multiple Inheritance

In multiple inheritance, a child class inherits from more than one parent class.

### Multiple Inheritance Example

class Father:

        self.age = age

    def speak(self):
        return 'Father speaks carefully.'
