Course coverage

The 46 source Python lessons are organized into 13 chapters here. Chapter 14 covers 21 AI terms, including the topics in your timestamp list and later concepts such as RAG and agents. The Python course includes exception handling and object-oriented programming from the source repository.

A practical study routine

  1. Read one chapter guide and trace its example by hand.
  2. Expand each lesson’s written notes. Type the examples into a .py file or notebook and change the inputs.
  3. Answer the four checked questions and write the final program before opening its solution.
  4. Run your program and compare behavior. Mark the chapter as read when you can explain it.
  5. Complete the projects using your own implementation. Add a README and actual results to your GitHub repository.

Progress and privacy

Drafts, solved questions and reading status use localStorage on this browser and device. They are not synced across devices. Clearing browser data removes them. Download or copy important work into your own files.
