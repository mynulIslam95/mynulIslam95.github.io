Core concepts

  • Ingestion হলো Fetch, Parse, Clean আর Metadata Save করা। Source URL, Retrieved Time আর Published Time জানা থাকলে আলাদা রাখো। Retrieved Time দিয়ে Publication Date অনুমান করবে না।
  • Chunking ছোট Search Units তৈরি করে। Heading ও Paragraph Boundary ধরে শুরু করো। Overlap দিলে Duplicate Evidence তৈরি হচ্ছে কি না Check করো।
  • Keyword Retrieval একটি Simple Baseline। Embeddings Semantic Similarity যোগ করে। Similarity Score থেকে সরাসরি Claim Truth বা Purchase Intent বের হয় না।
  • RAG-এ Retrieved Passages Context হিসেবে পাঠাবে। Source Text-এর Instructions-কে App Policy হিসেবে execute করবে না।
  • Citations-এ Source ID, URL ও Supporting Quote রাখো। Conflicting Sources থাকলে Date আর Credibility Review করে Uncertainty দেখাও।

Worked local lab

lab_4.py

import re
from dataclasses import dataclass

@dataclass(frozen=True)
class Passage:
    source_id: str
    url: str
    observed_at: str
    text: str

def terms(text: str) -> set[str]:
    return set(re.findall(r"[a-z0-9]+", text.lower()))

def retrieve(query: str, passages: list[Passage], limit: int = 2) -> list[Passage]:
    if limit < 1:
        raise ValueError("limit must be positive")
    query_terms = terms(query)
    scored = [(len(query_terms & terms(p.text)), p) for p in passages]
    scored.sort(key=lambda item: (-item[0], item[1].source_id))
    return [passage for score, passage in scored if score > 0][:limit]

if __name__ == "__main__":
    documents = [
        Passage("s1", "https://example.com/cloud", "2026-11-15",
                "Example Tools plans a cloud migration project."),
        Passage("s2", "https://example.com/cafe", "2026-11-15",
                "Example Cafe serves coffee and cake."),
    ]
    hits = retrieve("cloud migration", documents)
    assert [hit.source_id for hit in hits] == ["s1"]
    assert retrieve("marine insurance", documents) == []
    print(hits[0].source_id, hits[0].text)

python lab_4.py চালালে s1 আর তার Supporting Passage দেখাবে। Zero Overlap Query-এ Empty Results আসবে। Lab ছোট English Keyword Baseline, Bangla Search বা Semantic Retrieval যোগ করলে আলাদা Evaluation লাগবে।

Data lifecycle & retrieval trade-offs

এই Step-এর System Design Review-এ নিচের Decisions লিখবো আর Evidence দিয়ে ব্যাখ্যা করবো।

  1. চারটা Flow draw করো — Ingestion, Index Update, Query Retrieval আর Citation Resolution। প্রতিটি Boundary-তে Stored Fields ও Failure State দেখাও।
  2. Document Update বা Delete হলে Index, Cache আর Saved Evidence কীভাবে Refresh বা Retain হবে define করো। Report-এ কোন Source Version ব্যবহৃত হয়েছে রাখো।
  3. Retrieved Chunk-এ Tenant ও Source ACL Filter apply করো। Generation-এর পরে শুধু Text Hide করলে Retrieval Boundary-তে Unauthorized Data আগেই Leak হতে পারে।
  4. ADR-004-এ Keyword vs Hybrid Search compare করো। Same Labeled Query Set-এর Recall, Citation Support, Latency ও Cost দিয়ে Choice justify করো।
