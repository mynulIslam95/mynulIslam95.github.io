Industry-specific build briefs

  • IT Services — Service Catalogue, Supported Region আর Documented Need দিয়ে Client Fit। Evidence-backed Proposal Draft বানাও। Hiring Signal থেকে Confirmed Purchase Intent দাবি করবে না।
  • B2B SaaS — Product Use Case, Company Size আর Existing Workflow দিয়ে Product Fit। CRM Fields আর Qualification Reasons দেখাও।
  • Lead Generation Agency — Client Workspace, Client-specific Criteria, Data Isolation আর Approval Roles। একই Lead একাধিক Client-এর জন্য আলাদা Context পেতে পারে।
  • Recruitment — Employer ও Open Role Research, Hiring Source Date, Recruitment Service Fit আর Employer Outreach। Employer Research-এর Scope স্পষ্ট রাখো।
  • Industrial Sales — Product Specification, Geography, Distributor Coverage আর Procurement Requirements দিয়ে Buyer Fit। Missing Certification তথ্যকে Unknown রাখো।
  • Logistics — Shipping Need, Lanes, Geography আর Service Coverage-এর Documented Evidence ব্যবহার করো। Unknown Shipment Volume বা Frequency নিজে বানাবে না।

Worked configuration lab

lab_8.py

from dataclasses import dataclass

@dataclass(frozen=True)
class IndustryConfig:
    name: str
    required_fields: tuple[str, ...]
    report_focus: str

CONFIGS = {
    "it_services": IndustryConfig("IT Services", ("company", "service_need"), "service fit"),
    "saas": IndustryConfig("B2B SaaS", ("company", "use_case"), "product fit"),
    "lead_agency": IndustryConfig("Lead Generation", ("company", "client_id"), "client criteria"),
    "recruitment": IndustryConfig("Recruitment", ("company", "open_roles"), "hiring evidence"),
    "industrial": IndustryConfig("Industrial Sales", ("company", "product_category"), "buyer fit"),
    "logistics": IndustryConfig("Logistics", ("company", "shipping_need"), "service coverage"),
}

def validate_profile(industry: str, profile: dict) -> IndustryConfig:
    if industry not in CONFIGS:
        raise ValueError("Unsupported industry")
    config = CONFIGS[industry]
    missing = [field for field in config.required_fields if not profile.get(field)]
    if missing:
        raise ValueError("Missing fields: " + ", ".join(missing))
    return config

if __name__ == "__main__":
    config = validate_profile("it_services", {
        "company": "Example Tools", "service_need": "cloud migration"
    })
    print(config.name, config.report_focus)
    assert len(CONFIGS) == 6

Architecture review & release evidence

এই Step-এর System Design Review-এ নিচের Decisions লিখবো আর Evidence দিয়ে ব্যাখ্যা করবো।

  1. Functional Requirements-এর সাথে Demo ও Test map করো। Non-functional Targets-এর সাথে Load, Recovery, Security ও Cost Results map করো।
  2. Trust Boundary Diagram-এ Browser, API, Worker, Database, Model Provider আর CRM দেখাও। Credentials কোথায় থাকে আর কোন Data বাইরে যায় label করো।
  3. প্রতিটি ADR-এ Context, Alternatives, Chosen Approach, Consequences আর Revisit Trigger রাখো। Team-facing Handoff-এ Known Limitations ও Operational Decisions explain করো।
  4. Launch Review-এ Actual Pilot Evidence ব্যবহার করো। Missing Evidence-এর পাশে Not measured রাখো আর Planned Work-এর Status আলাদা দেখাও।
