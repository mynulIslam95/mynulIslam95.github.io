1.1.1 Variables and types

Variable হলো একটা value-এর নাম। amount_cents = 1250 লিখলে amount_cents দিয়ে 1250 value-টাকে refer করছি। int whole number, str text আর bool True/False রাখে। API থেকে "1250" এলে সেটা text, number না। type() দিয়ে সন্দেহটা check করো। এই Lesson-এ money integer cents-এ রাখবো, যাতে decimal rounding এখনই problem না হয়।
একটা lesson.py file বানাও। Terminal-এ python3 lesson.py দিয়ে run করো। তোমার machine-এ command python হলে সেটাই ব্যবহার করবে।

opening_cents = 10000
amount_cents = 1250
merchant = "Penny"
is_debit = True
print(type(amount_cents).__name__)
print(type("1250").__name__)
assert opening_cents - amount_cents == 8750

1.1.2 Conditions and comparisons

একটা debit-এর amount balance-এর চেয়ে বেশি হলে payment reject করবে। if, elif আর else দিয়ে এই decision লিখি। == compare করে, = value assign করে। and, or, not দিয়ে conditions combine করা যায়। Python-এ indentation block ঠিক করে, তাই একই block-এ consistent spaces রাখো। Empty string, zero আর empty collection false হিসেবে behave করে; business rule-এ zero valid কি না আগে ঠিক করো।

balance_cents = 8750
request_cents = 9000
if request_cents <= 0:
    result = "invalid"
elif request_cents > balance_cents:
    result = "insufficient_balance"
else:
    result = "approved"
assert result == "insufficient_balance"

1.1.3 for and while loops

একই কাজ প্রতিটি transaction-এর জন্য করলে for ব্যবহার করো। range(3) থেকে 0, 1, 2 আসে। কোনো condition true থাকা পর্যন্ত কাজ করলে while লাগে; condition বদলানোর ব্যবস্থা না থাকলে infinite loop হবে। continue current item skip করে, break loop থামায়। Report-এর জন্য total loop-এর আগে initialize করবে; ভেতরে reset করলে শুধু শেষ amount থাকবে।

amounts = [1250, 725, 8500]
total_cents = 0
alerts = []
for amount in amounts:
    total_cents += amount
    if amount > 8000:
        alerts.append(amount)
assert total_cents == 10475
assert alerts == [8500]
attempt = 0
while attempt < 2:
    attempt += 1
assert attempt == 2

1.1.4 Input validation

input() সবসময় text দেয়। এখানে integer cents-এর contract রাখছি: digits হলে accept, blank বা 12.50 হলে reject। strip() বাইরের whitespace সরায়। পরে Lesson 1.5-এ Decimal দিয়ে euro input parse করবো। Input conversion fail করতে পারে, তাই user input-কে number ভেবে calculation শুরু করবে না। Operator practice: +, -, *, /, // আর %; শেষ দুইটা quotient ও remainder দেয়।

raw = " 1250 "
cleaned = raw.strip()
if cleaned.isascii() and cleaned.isdigit():
    cents = int(cleaned)
    print(cents)
else:
    print("Enter a whole number of cents")
assert 1250 // 100 == 12
assert 1250 % 100 == 50

1.1.5 f-strings

Log বা receipt-এ value বসাতে f-string readable। {value} expression evaluate করে। Cents থেকে display-এর জন্য euro আর remainder আলাদা করি। :02d integer-কে অন্তত দুই digit দেখায়। Merchant name clean করতে strip(), compare করতে casefold() আর text ভাগ করতে split() কাজে লাগে। String immutable, তাই method call করে নতুন string ফেরত পাও; original নিজে বদলায় না।

merchant = "  Penny  ".strip()
cents = 1975
receipt = f"{merchant}: EUR {cents // 100}.{cents % 100:02d}"
print(receipt)
assert receipt == "Penny: EUR 19.75"
assert "PENNY".casefold() == "penny"

Debugging: কোথা থেকে শুরু করবে?

Report ভুল হলে আগে প্রতিটি variable-এর value ও type দেখো। Total loop-এর ভেতরে reset হয়েছে কি? Credit-কে debit ধরেছ? Zero amount reject করার rule কি consistent? একসাথে পাঁচটা change না করে সবচেয়ে ছোট failing input দিয়ে শুরু করো।

Practice 1: Shopping Balance

Opening balance €100। Debit €12.50 ও €7.25, credit €20। Total spent ও remaining balance বের করো।

Hint

সব amount cents-এ রাখো। Credit balance বাড়ায়, spent বাড়ায় না।

See Solution

Debit values যোগ করে spending বের করো; opening থেকে debit বাদ দিয়ে credit যোগ করো।

opening = 10000
debits = [1250, 725]
credit = 2000
spent = 0
for debit in debits:
    spent += debit
remaining = opening - spent + credit
print(f"Spent: EUR {spent / 100:.2f}")
print(f"Balance: EUR {remaining / 100:.2f}")
assert spent == 1975
assert remaining == 10025

নিজের কাজ মিলিয়ে দেখো

Expected spent €19.75 ও balance €100.25। Empty debit list দিয়েও result predict করে run করো।

Practice 2: Transaction Alerts

Amounts [1200, 0, -500, 9200]। শুধু positive transactions total করবে, €80-এর বেশি হলে alert list-এ রাখবে।

Hint

Invalid item-এ continue দাও। Alert-এর boundary > 8000, >= না।

See Solution

প্রথমে validation, তারপর total ও alert update করো।

amounts = [1200, 0, -500, 9200]
total = 0
alerts = []
for amount in amounts:
    if amount <= 0:
        continue
    total += amount
    if amount > 8000:
        alerts.append(amount)
assert total == 10400
assert alerts == [9200]

নিজের কাজ মিলিয়ে দেখো

8000 দিলে alert হবে না; 8001 দিলে হবে। এই দুই boundary নিজে test করো।
