1.1 Python Basics, Conditions & Loops

You have EUR 100. Build a program that checks each payment request, accepts the ones you can afford and shows how much money is left.

Operators & conditions

balance - amount gives the money left. amount > balance asks whether the payment is too large. A comparison gives True or False.

Use = to assign a value and == to compare two values. amount <= balance allows a payment equal to the balance.

and needs both checks to be true. or needs at least one to be true. not reverses a result.

To decide whether a single payment can go through, use if, elif and else. Python runs the first branch whose condition is true.

balance = 100
amount = 120
if amount <= 0:
    print("Amount must be positive")
elif amount > balance:
    print("Not enough balance")
else:
    print("Payment approved")

This prints Not enough balance. Change amount to 100 and predict what happens.

Loops

A for loop repeats an action for each item. If you need a set number of turns, for turn in range(3): gives you the values 0, 1 and 2. The report below loops through payment requests instead.

Create payments.py in your practice folder. Save the code and run py -3 payments.py on Windows or python3 payments.py on Mac or Linux.

balance = 100
requests = [" 12 ", "oops", "120", "8", "0"]
spent = 0

for raw in requests:
    text = raw.strip()
    if not (text.isascii() and text.isdigit()):
        print("Enter a whole number")
        continue

    amount = int(text)
    if amount <= 0:
        print("Amount must be positive")
    elif amount > balance:
        print("Not enough balance")
    else:
        balance -= amount
        spent += amount
        print(f"Paid: EUR {amount}")

print(f"Spent: EUR {spent}")
print(f"Balance: EUR {balance}")

Expected output

Paid: EUR 12
Enter a whole number
Not enough balance
Paid: EUR 8
Amount must be positive
Spent: EUR 20
Balance: EUR 80

3. Follow the loop

  1. for raw in requests takes one item at a time. The square brackets hold a list. The indented lines belong to the loop.
  2. " 12 " becomes "12", then the number 12. It passes both checks, so the else block reduces the balance from EUR 100 to EUR 88. balance -= amount means balance = balance - amount.
  3. "oops" fails the text check. continue skips the rest of this turn. Next, 120 is larger than EUR 88, so that payment is declined.
  4. 8 is approved and leaves EUR 80. 0 fails the positive-amount check. The two unindented print() lines run once after the loop.

if checks the first rule. elif checks the next rule if the first one fails. else runs if both rules fail. Keep the indents consistent, using four spaces per level.

Use for when you have a list of items. Use while when you need to repeat until a condition changes. This example prints 1, 2 and 3.

attempts = 0
while attempts < 3:
    attempts += 1
    print(attempts)

Without attempts += 1, the condition would stay true. break stops the entire loop when you need to exit early.

4. Check input before converting it

strip() removes spaces at the ends. isascii() and isdigit() together accept digit-only text such as "12". This example rejects blanks, negative amounts and prices with a decimal point. A second check rejects zero.

Common mistake. Keep spent = 0 above the loop. Put it inside and you’ll reset the total on every turn.

If you need a reminder about input(), int() or f-strings, see Variables, data types & strings.
