1.1.1 Variables and types

Python 3.11 বা newer ব্যবহার করো। python3 --version দিয়ে version দেখো। Command না পাওয়া গেলে Python install করে terminal আবার খোলো। Script save করার পরে run করো; শুধু file edit করলে পুরোনো terminal output বদলাবে না।

ধরো, তোমার account-এ €100 আছে। Penny-তে €12 খরচ করলে কত থাকবে? আগে Python-কে এই দুইটা value জানাই। Variable হলো value-কে refer করার একটা নাম। balance = 100-এ balance নামটা 100 value-এর সঙ্গে associate হচ্ছে। = এখানে assignment, equality check না।
প্রথমে lesson.py file বানিয়ে নিচের code save করো। Terminal-এ python3 lesson.py run করো। তোমার machine-এ Python command python হলে সেটাই ব্যবহার করবে। print() বন্ধনীর ভেতরের value screen-এ দেখায়।

Code-টা run করি

balance = 100
expense = 12
remaining = balance - expense
print(remaining)
print(balance)

Output

88
100

কীভাবে এই result হলো?

  1. প্রথম line-এ balance-এর value 100। দ্বিতীয় line-এ expense-এর value 12।
  2. তৃতীয় line-এ আগে ডান পাশ evaluate হয়: 100 - 12 = 88। তারপর remaining নামের সঙ্গে 88 associate হয়।
  3. print(remaining) তাই 88 দেখায়। balance assign করা হয়নি, তাই print(balance) এখনো 100 দেখায়।
এখানে যেটা ভুল হতে পারে

নতুন result অন্য variable-এ রাখলে original variable নিজে থেকে update হয় না। balance update করতে balance = balance - expense লিখবে। তখন ডান পাশে পুরোনো balance ব্যবহার হয়, assignment-এর পরে balance 88 হয়।

Value-এর type-ও গুরুত্বপূর্ণ। 100 হলো int, 12.5 হলো float, "Penny" হলো str আর True হলো bool। Quotes থাকলে "100" text, number না। print(type(balance)) দিয়ে type দেখতে পারো। Int আর string যোগ-বিয়োগ একভাবে করা যায় না। Naming-এ opening_balance readable; 2balance invalid। Production money-এর exact decimal handling Lesson 1.5-এ করবো; এখানে arithmetic বোঝার জন্য whole euros ব্যবহার করছি।

এবার তুমি বদলে দেখো

শেষে balance = balance - expense লিখে দুবার run করো, অর্থাৎ একই script-এ এই assignment দুই line রাখো। Final balance কত?

Reasoning মিলিয়ে দেখো

প্রথম update-এ 100 - 12 = 88, দ্বিতীয় update-এ 88 - 12 = 76। পুরো script নতুন করে run করলে আবার প্রথম line থেকে balance 100 দিয়ে শুরু হবে।

1.1.2 Conditions and comparisons

এবার customer €120 pay করতে চাইছে, কিন্তু balance €100। Calculation-এর আগে decision লাগবে: amount positive কি, আর balance যথেষ্ট কি? if true condition-এর indented block চালায়। false হলে elif check হয়, শেষে else fallback। :-এর পরে block শুরু; একই block-এ চারটা space রাখো।

Code-টা run করি

balance = 100
requested = 120
if requested <= 0:
    print("Invalid amount")
elif requested > balance:
    print("Not enough balance")
else:
    print("Payment approved")

Output

Not enough balance

কীভাবে এই result হলো?

  1. 120 <= 0 false, তাই প্রথম print execute হয় না।
  2. 120 > 100 true, তাই দ্বিতীয় print চলে।
  3. একটা branch match হলে এই if/elif/else chain-এর বাকি branches আর execute হয় না।
এখানে যেটা ভুল হতে পারে

requested = balance value overwrite করে। Compare করতে requested == balance লিখবে। >= মানে greater-or-equal; > শুধু greater। তিনটা independent if লিখলে একই input-এ একাধিক branch চলতে পারে।

দুই condition একসাথে চাইলে and, যেকোনো একটা হলে or, condition উল্টাতে not। যেমন requested > 0 and requested <= balance valid range check করে। Empty string আর zero false হিসেবে behave করলেও business rule explicit করে লেখা শুরুতে clearer।

এবার তুমি বদলে দেখো

requested 100, 0 আর -5 দিয়ে আলাদা করে run করো। কোন branch চলবে আগে লিখে নাও।

Reasoning মিলিয়ে দেখো

100 হলে first condition false, দ্বিতীয়টাও false, তাই approved। 0 ও -5 হলে প্রথম condition true, তাই invalid। Exact boundary-তে policy বোঝা যায়।

1.1.3 for and while loops

এখন তিনটা expense €12, €8 আর €5। আলাদা আলাদা যোগ না করে প্রতিটি amount-এর জন্য একই কাজ করবো। [12, 8, 5] একটা list, অর্থাৎ ordered values-এর group; পরের Lesson-এ lists বিস্তারিত দেখবো। for amount in expenses প্রতি iteration-এ পরের value amount নামের সঙ্গে associate করে।

Code-টা run করি

expenses = [12, 8, 5]
total = 0
for amount in expenses:
    total = total + amount
    print(total)
print("Done")

Output

12
20
25
Done

কীভাবে এই result হলো?

  1. Loop শুরুর আগে total 0। প্রথম amount 12, তাই total 0 + 12 = 12।
  2. দ্বিতীয় amount 8। আগের total 12 ব্যবহার করে এবার total 20।
  3. তৃতীয় amount 5 দিয়ে total 25। Loop শেষ হলে unindented print একবার Done দেখায়।
এখানে যেটা ভুল হতে পারে

total = 0 loop-এর ভেতরে রাখলে প্রতিবার আগের progress মুছে যাবে। total += amount এই integer example-এ total = total + amount-এর short form।

while condition true থাকা পর্যন্ত চলে। যেমন attempts = 0 দিয়ে শুরু করে while attempts < 3:-এর ভেতরে attempts += 1 দিলে 3 বার চলে। Update বাদ দিলে loop থামবে না। continue current iteration-এর বাকি অংশ skip করে, break পুরো loop থামায়।

এবার তুমি বদলে দেখো

expenses empty list [] করে run করো। total print করতে চাইলে loop-এর পরে print(total) যোগ করো।

Reasoning মিলিয়ে দেখো

Loop body একবারও চলবে না। total 0 থাকবে। তারপর Done ও 0 print হবে। তাই accumulator loop-এর বাইরে initialize করা জরুরি।

1.1.4 Input validation

User যে input দেয় সেটা আগে text হিসেবে আসে। তাই "12" আর 12 এক না। Decimal euros parse না করে এখানে whole-euro input accept করছি। strip() text-এর বাইরের whitespace বাদ দিয়ে নতুন text দেয়। Dot-এর পরে method call মানে এই text-এর উপর operation।

Code-টা run করি

raw = " 12 "
cleaned = raw.strip()
if cleaned.isascii() and cleaned.isdigit():
    amount = int(cleaned)
    print(amount + 1)
else:
    print("Enter whole euros")

Output

13

কীভাবে এই result হলো?

  1. raw-এর দুই পাশে space আছে; strip() থেকে cleaned হয় "12"।
  2. isascii() আর isdigit() মিলে এখানে সাধারণ ASCII digits accept করছে। দুইটা check true হলে and true।
  3. int("12") number 12 দেয়, তাই 12 + 1 থেকে 13। Invalid text হলে conversion না করে else message দেবে।
এখানে যেটা ভুল হতে পারে

raw + 1 করলে TypeError, কারণ string আর integer। আর raw + "1" text জোড়া লাগায়, যোগ করে না। এই rule decimal ও negative input reject করে, সেটাই এই ছোট form-এর contract।

Live input নিতে প্রথম line raw = input("Amount in whole euros: ") করবে। Prompt শেষ হলে Enter চাপো। Parsing সফল মানে business rule valid, এমন না: number হওয়া ও positive হওয়া আলাদা check।

এবার তুমি বদলে দেখো

raw-তে "oops", "12.50" আর "" দিয়ে run করো। এই form zero accept করবে কি?

Reasoning মিলিয়ে দেখো

তিনটাই else-এ যাবে। "0" digit হওয়ায় conversion হবে এবং 1 print করবে। Transaction-এর জন্য positive amount চাইলে conversion-এর পরে amount > 0 check যোগ করতে হবে।

1.1.5 f-strings

Receipt-এ merchant, expense আর remaining balance একসাথে দেখাতে চাই। f prefix থাকলে string-এর curly braces-এর expression evaluate হয়। Prefix না থাকলে braces-সহ literal text print হবে।

Code-টা run করি

merchant = "Penny"
balance = 100
expense = 12
remaining = balance - expense
print(f"{merchant}: spent EUR {expense}")
print(f"Remaining: EUR {remaining}")

Output

Penny: spent EUR 12
Remaining: EUR 88

কীভাবে এই result হলো?

  1. remaining calculate হচ্ছে 100 - 12 থেকে।
  2. প্রথম f-string-এর {merchant} জায়গায় Penny আর {expense} জায়গায় 12 বসে।
  3. দ্বিতীয় string-এর remaining 88। Formatting result দেখায়, balance update করার কাজ করে না।
এখানে যেটা ভুল হতে পারে

print("Remaining: {remaining}")-এ f নেই, তাই value বসবে না। {remaining:.2f} display-এ দুই decimal place দেখায়; এতে underlying value বা money validation বদলায় না।

Text compare-এ casefold() useful: "PENNY".casefold() ও "penny".casefold() একই। "T1,debit".split(",") দুই অংশের list দেয়, তবে real CSV-তে quoted commas থাকতে পারে। তাই CSV parser Lesson 1.5-এ ব্যবহার করবো।

এবার তুমি বদলে দেখো

প্রথম line-এর merchant-এর বদলে " PENNY " দাও। Receipt clean করতে কী করবে?

Reasoning মিলিয়ে দেখো

merchant = merchant.strip().title() দিলে বাইরের spaces বাদ দিয়ে Penny পাওয়া যায়। Method chain-এর প্রতিটি step নতুন string return করে। Original variable বদলাতে returned result assign করতে হয়।

Debugging: কোথা থেকে শুরু করবে?

Report ভুল হলে আগে প্রতিটি variable-এর value ও type দেখো। Total loop-এর ভেতরে reset হয়েছে কি? Credit-কে debit ধরেছ? Zero amount reject করার rule কি consistent? একসাথে পাঁচটা change না করে সবচেয়ে ছোট failing input দিয়ে শুরু করো।

Practice 1: নিজের Balance Report

Opening €100। Penny-তে €12, restaurant-এ €8 খরচ। তারপর €20 credit এসেছে। Total spent ও final balance print করো।

Hint

আগে spent = 12 + 8। Credit spending বাড়ায় না।

See Solution

প্রথমে expense total, তারপর opening - spent + credit।

Solution-টা বুঝে নিই

Penny আর restaurant values আগে যোগ হয়েছে। Credit শুধু balance formula-তে আছে, spent-এ নেই। তাই spent 20 হলেও final balance আবার 100।

opening = 100
penny = 12
restaurant = 8
credit = 20
spent = penny + restaurant
balance = opening - spent + credit
print(f'Spent: EUR {spent}')
print(f'Balance: EUR {balance}')

Output

Spent: EUR 20
Balance: EUR 100

নিজের কাজ মিলিয়ে দেখো

Output Spent: EUR 20 এবং Balance: EUR 100। Credit বাদ দিলে balance 80 হয় কি না দেখো। এখানে list বা exception ব্যবহার করার দরকার নেই।

Practice 2: Invalid Expense বাদ দাও

Expenses [12, 0, -5, 92]। শুধু positive expenses যোগ করবে। €80-এর বেশি হলে সেই amount-এর alert print করবে। শেষে total print করো।

Hint

Loop-এ আগে amount <= 0 হলে continue। Alert check valid amount-এর পরে।

See Solution

প্রতিটি valid amount total-এ যোগ হয়। Invalid values total-এ ঢোকে না।

Solution-টা বুঝে নিই

continue 0 ও -5-এর বাকি processing skip করেছে। শুধু 12 ও 92 total-এ গেছে। Alert-এর condition true হয়েছে শুধু 92-এ।

expenses = [12, 0, -5, 92]
total = 0
for amount in expenses:
    if amount <= 0:
        continue
    total = total + amount
    if amount > 80:
        print(f'Review: EUR {amount}')
print(f'Total: EUR {total}')

Output

Review: EUR 92
Total: EUR 104

নিজের কাজ মিলিয়ে দেখো

Output Review: EUR 92 ও Total: EUR 104। 80 দিলে review হবে না, 81 দিলে হবে।
