1.7.1 Annotations and generic types

Type hints developer ও static checker-কে expected types জানায়। Python নিজে hint দেখে input reject করে না। list[int], dict[str, int] দিয়ে collection structure বোঝাও। Boundary-তে runtime validation আলাদা লাগবে। এই Module-এর code Python 3.11+ syntax ব্যবহার করে। Interpreter version python3 --version দিয়ে check করো।

def total_cents(amounts: list[int]) -> int:
    return sum(amounts)

assert total_cents([100, 250]) == 350
# A type checker can flag a list[str] passed to total_cents.
# Python annotations alone do not validate that input.

1.7.2 Dataclasses and Optional

str | None মানে value text অথবা absent। এটা optional business value বোঝায়; function argument automatically optional হয়ে যায় না, default লাগবে। Missing owner-কে empty string দিয়ে represent করলে unassigned আর invalid blank name মিশে যায়। Dataclass দিয়ে record shape declare করো, None explicitly handle করো।

from dataclasses import dataclass

@dataclass
class Ticket:
    title: str
    owner: str | None = None

def owner_label(ticket: Ticket) -> str:
    if ticket.owner is None:
        return "unassigned"
    return ticket.owner

assert owner_label(Ticket("Refund")) == "unassigned"
assert owner_label(Ticket("Refund", "Mynul")) == "Mynul"

1.7.3 Naming and refactoring

Refactor মানে externally expected behavior ঠিক রেখে internal structure improve করা। আগে expected input/output লিখো, তারপর duplicated rule বা mixed responsibility আলাদা করো। Money-তে unit name-এ রাখো: amount_cents। x, data2 দিয়ে business meaning হারাবে না। Type checker pass করলেও wrong rule থাকতে পারে; tests লাগবে।

def is_large_debit(amount_cents: int, threshold_cents: int = 8000) -> bool:
    return amount_cents > threshold_cents

def large_debits(amounts: list[int]) -> list[int]:
    return [amount for amount in amounts if is_large_debit(amount)]

assert large_debits([8000, 8001, 0]) == [8001]

1.7.4 venv and pip

Project-এর packages আলাদা environment-এ রাখলে unrelated project-এর dependency conflict কমে। python -m pip লিখলে কোন interpreter-এর pip ব্যবহার হচ্ছে clearer থাকে। Editor-এও সেই .venv interpreter select করবে। নিচের commands terminal-এ run করো। Linux/macOS-এ activate command source .venv/bin/activate; Windows PowerShell-এ .venv\Scripts\Activate.ps1। Activation policy বাধা দিলে .venv-এর Python executable সরাসরি ব্যবহার করা যায়।

python3 -m venv .venv
# Linux/macOS:
source .venv/bin/activate
python -m pip install pytest==8.3.5 ruff==0.11.13 mypy==1.15.0
python -c "import sys; print(sys.executable)"
python -m pip freeze > requirements-dev.txt

1.7.5 pyproject.toml and formatting

pyproject.toml project metadata আর tool configuration এক জায়গায় রাখে। এটা একা resolved dependency lock নয়। ছোট app-এর reproducible setup-এর জন্য tested dependency versions record ও clean environment-এ verify করো। Direct packages আর transitive packages-এর difference বুঝে রাখো। Formatting, linting আর type checking আলাদা checks; formatter business bug fix করে না। এই example-এর version pins learning setup-এর জন্য। নিজের project-এ updates review ও test করে নেবে।

[project]
name = "transaction-tracker"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = []

[tool.ruff]
line-length = 88
target-version = "py311"

[tool.mypy]
python_version = "3.11"
check_untyped_defs = true

File-টা project root-এ pyproject.toml নামে রাখো। python -m ruff check ., python -m ruff format --check . আর python -m mypy tracker.py আলাদা command। Tool install না থাকলে আগে উপরের dev setup করো।

Debugging: কোথা থেকে শুরু করবে?

Terminal-এ import works কিন্তু editor-এ fail? Interpreter path compare করো। Hint আছে বলে invalid API payload safe মনে হচ্ছে? Runtime validation test করো। Package install হওয়ার পরে dependency conflict দেখলে clean environment-এ reproduce করো।

Practice 1: Typed Customer Lookup

Customer map থেকে name return করো। ID missing হলে None। Caller None handle করে label দেখাবে।

Hint

Return type str | None রাখো। Missing-কে existing empty value-এর সঙ্গে মিলাবে না।

See Solution

Dict.get দিয়ে missing represent করো, caller explicit None branch দেবে।

def find_customer(customers: dict[int, str], customer_id: int) -> str | None:
    return customers.get(customer_id)

customers = {42: "Mynul"}
assert find_customer(customers, 42) == "Mynul"
missing = find_customer(customers, 7)
label = "unknown customer" if missing is None else missing
assert label == "unknown customer"

def review_status(amount_cents: int) -> str:
    if amount_cents < 0:
        raise ValueError("Amount cannot be negative")
    return "review" if amount_cents > 8000 else "normal"

assert review_status(0) == "normal"
assert review_status(8000) == "normal"
assert review_status(8001) == "review"
