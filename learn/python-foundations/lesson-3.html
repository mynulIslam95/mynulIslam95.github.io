1.3 Functions, Scope & Modules

Transaction fee calculate করার code তিন জায়গায় copy হয়েছে। এক জায়গায় rule বদলেছে, অন্য দুই জায়গায় পুরোনো rule। এবার calculation-টা ছোট function-এ রাখবো, যাতে input/output পরিষ্কার থাকে আর test করা সহজ হয়।

এই Lesson শেষে: Reusable functions লিখতে, mutable default bug এড়াতে আর script-কে modules-এ ভাগ করতে পারবে।

1.3.1 Parameters and returns

Function-এর parameter হলো input, return হলো result। print() screen-এ দেখায়, কিন্তু caller-কে calculated value ফেরত দেয় না। Reuse করতে চাইলে result return করো। এখানে fee calculation-এর contract: amount nonnegative integer cents, basis points nonnegative integer। 100 basis points মানে 1%। এই example-এ fraction of a cent floor করবো, কারণ rounding rule explicit হওয়া দরকার।

def fee_cents(amount_cents, basis_points):
    if amount_cents < 0 or basis_points < 0:
        raise ValueError("Inputs must be nonnegative")
    return amount_cents * basis_points // 10000

fee = fee_cents(10000, 250)
assert fee == 250

1.3.2 Default arguments

Default value function define হওয়ার সময় evaluate হয়। def add(item, items=[]) লিখলে একই list calls-এর মধ্যে reuse হয়। Result: এক request-এর data অন্য request-এ দেখা যায়। Optional mutable input-এর default None রাখো, function-এর ভেতরে fresh collection বানাও। Caller list দিলে সেটা mutate করবে কি নতুন copy ফেরত দেবে contract-এ বলো।

def add_tag(tag, tags=None):
    result = [] if tags is None else list(tags)
    result.append(tag)
    return result

assert add_tag("billing") == ["billing"]
assert add_tag("urgent") == ["urgent"]
original = ["open"]
assert add_tag("review", original) == ["open", "review"]
assert original == ["open"]

1.3.3 Scope and pure functions

Function-এর local variable বাইরের একই নামের variable change করে না। Module-level global state edit করলে tests order-dependent হতে পারে। Pure function একই input-এ একই output দেয় আর বাইরের state change করে না। Fee বা summary calculation pure রাখলে easy tests পাওয়া যায়। Network call, file write আর current time-এর মতো changing dependency আলাদা boundary-তে রাখো। global দিয়ে balance update করার বদলে নতুন value return করা সাধারণত clearer।

balance = 10000

def apply_debit(current_balance, amount):
    if amount <= 0 or amount > current_balance:
        raise ValueError("Invalid debit")
    return current_balance - amount

updated = apply_debit(balance, 2500)
assert balance == 10000
assert updated == 7500

1.3.4 Imports and modules

একটা .py file-ই module। Calculation fees.py-তে, CLI entry point main.py-তে রাখো। Import করলে module-এর top-level code execute হয়, তাই input prompt বা file write import-এর সময় করাবে না। if __name__ == "__main__" entry point guard রাখো। নিজের file-এর নাম json.py বা logging.py রাখলে standard library import shadow হতে পারে। নিচের standalone file run করলে main চলে; import করলে শুধু function পাওয়া যায়।

def summarize(amounts):
    return {"count": len(amounts), "total_cents": sum(amounts)}

def main():
    print(summarize([100, 250]))

if __name__ == "__main__":
    main()

assert summarize([]) == {"count": 0, "total_cents": 0}

1.3.5 Docstrings and decomposition

একটা function-এর নাম দেখে কাজ বোঝা উচিত। process()-এর বদলে summarize_debits() clearer। Docstring-এ input unit, output আর surprising rule লিখো। Parse, validate, calculate আর display এক function-এ ঠেসে দিও না। আবার এক লাইনের প্রতি expression-এর জন্য class/function বানানোরও দরকার নেই। Meaningful boundary বেছে নাও।

def summarize_debits(amounts):
    """Return count and total for positive integer-cent debits."""
    valid = [amount for amount in amounts if amount > 0]
    return {"count": len(valid), "spent_cents": sum(valid)}

assert summarize_debits([500, -20, 0, 100]) == {
    "count": 2, "spent_cents": 600
}

Debugging: কোথা থেকে শুরু করবে?

Caller None পাচ্ছে? Function-এ return আছে কি না দেখো। Calls-এর মধ্যে আগের values থাকছে? Mutable default আছে কি না দেখো। Import-এর সময় CLI শুরু হচ্ছে? Entry-point guard check করো।

Practice 1: Reusable Fee Function

amount_cents ও rate_bps নিয়ে fee return করো। Negative input reject করবে; floor-to-cent rule রাখবে।

Hint

Return দিয়ে result দাও। 250 bps মানে 2.5%, 250% না।

See Solution

Basis points-কে 10000 দিয়ে ভাগ করি। Negative validation আগে করি।

def calculate_fee(amount_cents, rate_bps=250):
    if amount_cents < 0 or rate_bps < 0:
        raise ValueError("Negative amount or rate")
    return amount_cents * rate_bps // 10000

assert calculate_fee(10000) == 250
assert calculate_fee(0) == 0
assert calculate_fee(199, 100) == 1
try:
    calculate_fee(-1)
except ValueError:
    pass
else:
    raise AssertionError("Negative amount was accepted")

নিজের কাজ মিলিয়ে দেখো

Boundary 0, default rate আর one fractional-cent result explain করো।

Practice 2: No Shared Request History

append_event(event, history=None) লিখো। Result-এ event থাকবে, caller history বদলাবে না।

Hint

Fresh result list বানাও; passed list-ও copy করবে।

See Solution

Function-এর বাইরে state রাখার প্রয়োজন নেই।

def append_event(event, history=None):
    result = [] if history is None else list(history)
    result.append(event)
    return result

old = ["received"]
assert append_event("validated", old) == ["received", "validated"]
assert old == ["received"]
assert append_event("new") == ["new"]
assert append_event("other") == ["other"]

নিজের কাজ মিলিয়ে দেখো

দুই consecutive call independent আর existing list unchanged হতে হবে।
