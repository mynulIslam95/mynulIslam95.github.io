1.5.1 try/except and error categories

Exception হলো normal execution থামিয়ে caller-কে problem জানানোর mechanism। ValueError invalid value, FileNotFoundError missing file, KeyError missing dict key। শুধু যেই error recover করতে পারো সেটাই catch করো। except Exception: pass দিলে data loss লুকাতে পারে। Input error-এ useful message দাও; unexpected bug-এর traceback রাখো। finally cleanup-এর জন্য, আর raise ... from error root cause preserve করে।

def parse_count(raw):
    try:
        count = int(raw)
    except ValueError as error:
        raise ValueError("Count must be a whole number") from error
    if count < 0:
        raise ValueError("Count cannot be negative")
    return count

assert parse_count("3") == 3
try:
    parse_count("three")
except ValueError as error:
    print(error)
    assert isinstance(error.__cause__, ValueError)

1.5.2 pathlib and context managers

Relative path current working directory থেকে resolve হয়, script-এর folder থেকে automatically না। Path দিয়ে paths compose করো। with file success বা failure দুই অবস্থাতেই close করতে সাহায্য করে। encoding="utf-8" explicit রাখো, যাতে Bangla text machine বদলালেও readable থাকে। গুরুত্বপূর্ণ report overwrite করার সময় same-directory temporary file লিখে replace করা safer pattern; atomic replace মানেই crash durability বা backup guarantee না।

from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as folder:
    path = Path(folder) / "report.txt"
    with path.open("w", encoding="utf-8") as handle:
        handle.write("Report ready: বাংলা")
    with path.open(encoding="utf-8") as handle:
        text = handle.read()
    assert "বাংলা" in text

1.5.3 CSV parsing

CSV text manual split(",") করলে quoted comma ভেঙে যেতে পারে। csv.DictReader header দিয়ে dict বানায়। Field values strings থাকে, conversion ও required-field validation তোমাকে করতে হবে। newline="" দিয়ে file open করলে csv module newline handle করতে পারে। Bad row skip করলে row number ও safe reason রাখো; silent skip হলে audit করা কঠিন।

import csv
from io import StringIO

source = StringIO('id,merchant,amount_cents\nT1,"Shop, Berlin",1250\nT2,Penny,725\n')
rows = list(csv.DictReader(source))
assert rows[0]["merchant"] == "Shop, Berlin"
assert sum(int(row["amount_cents"]) for row in rows) == 1975

1.5.4 JSON serialization

JSON data interchange format। Python dict/list থেকে json.dumps() text বানায়, json.loads() text থেকে objects ফেরত দেয়। JSON true/null Python-এ True/None হয়। Decimal, datetime বা custom class default encoder সরাসরি জানে না; stable explicit representation বেছে নাও। Money decimal string বা integer cents হিসেবে রাখো। Untrusted data-তে eval() করবে না।

import json

report = {"currency": "EUR", "spent_cents": 1975, "valid": True}
encoded = json.dumps(report, ensure_ascii=False, allow_nan=False)
decoded = json.loads(encoded)
assert decoded == report
assert decoded["valid"] is True

1.5.5 Decimal for money

0.1 + 0.2 binary floating point-এ exactly 0.3 নাও হতে পারে। Monetary input-এর জন্য Decimal("12.50") string থেকে বানাও। Decimal(0.1) করলে already approximated float-এর value ঢুকে যায়। Finite check জরুরি: NaN ও Infinity valid payment না। এই course-এর input rule: amount positive এবং cent-এর নিচে fraction থাকবে না। Display-এ .2f দিলেই invalid business amount validate হয়ে যায় না।

from decimal import Decimal, InvalidOperation

def parse_euros(raw):
    try:
        amount = Decimal(raw.strip())
    except InvalidOperation as error:
        raise ValueError("Invalid amount") from error
    if not amount.is_finite() or amount <= 0:
        raise ValueError("Positive finite amount required")
    if amount != amount.quantize(Decimal("0.01")):
        raise ValueError("Use whole cents")
    return amount

assert parse_euros("12.50") == Decimal("12.50")

Practice 1: CSV Import with Rejections

CSV-এর amount_cents whole positive integer হতে হবে। Good rows total করো, bad row numbers আলাদা রাখো।

Hint

DictReader-এ enumerate start=2 দাও, কারণ header row 1।

See Solution

প্রতিটি row-কে আলাদাভাবে validate করো; একটি bad row পুরো batch থামাবে না।

import csv
from io import StringIO

source = StringIO("id,amount_cents\nT1,1250\nT2,oops\nT3,-2\nT4,725\n")
total = 0
rejected = []
for line, row in enumerate(csv.DictReader(source), start=2):
    try:
        amount = int(row["amount_cents"])
        if amount <= 0:
            raise ValueError("Nonpositive amount")
    except (ValueError, TypeError):
        rejected.append(line)
        continue
    total += amount
assert total == 1975
assert rejected == [3, 4]

নিজের কাজ মিলিয়ে দেখো

Malformed file header batch-level error, bad value row-level error। Missing amount_cents header আলাদা করে reject করার check নিজে যোগ করো।

Practice 2: Safe Money to JSON

Positive euro amount string থেকে integer cents return করো। NaN, Infinity, blank, negative আর fractional cent reject করো। Result JSON encode করো।

Hint

Decimal finite check comparison-এর আগে; float conversion এড়াও। এই exercise input length 30 characters limit রাখো।

See Solution

Bound input, parse, finite/range check, cent validation, তারপর integer conversion।

import json
from decimal import Decimal, InvalidOperation

def to_cents(raw):
    text = raw.strip()
    if not text or len(text) > 30:
        raise ValueError("Invalid input length")
    try:
        value = Decimal(text)
    except InvalidOperation as error:
        raise ValueError("Invalid amount") from error
    if not value.is_finite() or not (0 < value <= Decimal("1000000")):
        raise ValueError("Amount outside allowed range")
    if value * 100 != (value * 100).to_integral_value():
        raise ValueError("Fractional cents")
    return int(value * 100)

assert to_cents("12.50") == 1250
for bad in ("NaN", "Infinity", "", "-1", "1.001"):
    try:
        to_cents(bad)
    except ValueError:
        pass
    else:
        raise AssertionError(f"Accepted invalid input: {bad}")
assert json.loads(json.dumps({"amount_cents": to_cents("7.25")}))["amount_cents"] == 725

Good amount round-trip হবে। প্রতিটি invalid value ValueError দেবে।
