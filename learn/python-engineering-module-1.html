Python for Forward Deployed Engineers

Write your first Python script, turn customer data into a usable report and build a service checker that can handle slow or failed requests.

Start learning Python

Study route · Lecture and assignment map

What you’ll build

  • A customer onboarding script that checks input and prints a handoff.
  • A tested command-line tool that reads and reports on customer data.
  • Customer Integration Checker, a project you can start with functions and build through testing, concurrency and customer handoff.

Study route and checkpoints

  1. Get moving. Start with setup and variables, then practice conditions and loops. Close the answer and trace a payment at the exact balance.
  2. Structure a small program. Learn functions, collections and objects. Explain a returned value and fix a shared-list bug.
  3. Handle customer data. Do the worked labs for exceptions and files, generators, modules and testing. Prove a bad record is reported and an off-by-one bug fails a test.
  4. Run concurrent checks and hand them over. Work through async and concurrency and the worker-pool lab. Finish with the Customer Integration Checker and explain its partial results to the next engineer.

Before opening a solution, predict the output or error. Run the code, compare the result and use the line-by-line walkthrough when a step is unclear. Rerun it with one changed input.
