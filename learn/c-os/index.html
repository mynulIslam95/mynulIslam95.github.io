C programming for Operating System

This course sits outside the OS classroom. No shop stories. Ten chapters, each a long rule then a large practice set. Then three big projects — easy, medium, hard — that use all ten chapters. Every item has Hint (step by step), Submit, and See answer. The answer is C with comments on every important line. After the hard project, you can publish your own share.c on GitHub. Start at Chapter 1 if you have never written C.

How to practice

Read the rule. Trace: what is in the box, which line runs next, what comes back. Then do every drill. Submit first. Open See answer only after you try. Logic is the skill. Typing is second.
