C for OS · Chapter 3

Print and read — printf, scanf

Format vs value. What prints. What is still unknown until you read it. Labs print a pid or a pin. perror is also a print after a failed call.

Jump to practice Ch2 variables

1. printf is a function call

You already wait for functions in Chapter 7. Here you only need: you call printf. What goes in: a format string, then values. The screen shows text. main waits until printing is done.

#include <stdio.h>

int main(void) {
  int x = 5;
  printf("%d\n", x);
  return 0;
}
The rule

%d is a hole for an int. \n is a new line. The value after the comma fills the hole. The format is not the value. "%d\n" is instructions. x is the number.

2. Holes you need

  • %d — int (pid, count, fd, return code)
  • %c — one char
  • %s — string (paper to the first character, Chapter 6/8)
  • %% — a real percent sign

Wrong hole: printf("%d\n", "hello"); is undefined. Match the type. Two holes need two values: printf("%d %d\n", a, b);

Text around holes is copied as-is: printf("pid=%d\n", r); prints pid= then the number then a newline.

3. Newline

Without \n, the next print sticks to the same line. Traces in this course always show a newline when the code has \n. Type what you would see, including spaces, not the quotes.

4. scanf — read into a box

int x;
scanf("%d", &x);   /* paper to x. Chapter 8 is the star. here: MUST use & */

scanf must know which box to fill. So you pass the address &x, not the value of x (which is garbage anyway). Forgetting & is a crash or a silent disaster.

What goes in: format, then papers. What comes back: how many boxes were filled, or EOF. Who waits: main waits until the user types (or input fails).

OS labs rarely use scanf. They print. You still need this so & is not new in Chapter 8: you already passed an address so a function could write your box.

5. perror — print why a call failed

if (fd == -1) {
  perror("shm_open");
  return 1;
}

perror prints your label, then the OS reason (permission, no such file, …). It is still a function you call after a failed OS call. Include stdio.h.

OS door

Print r after fork, print getpid(), print a GPIO value. Same %d. Do not print a pointer with %d (Chapter 8 uses %p if you must). Prefer printing *p (the box) not the paper.
