C for OS · Project 1 · easy

Mini process table

A big, real program. One file: desk.c. A table of fake processes. Add, list, find, “kill” (set alive to 0). Menu loop until quit. You do not call real fork yet. You use Chapters 1–10 as C: file, boxes, print, if, loops, arrays, functions, pointers, structs, headers.

Jump to steps Ch10 P2 medium

What you will have when it is done

A program you compile with gcc desk.c -o desk and run with ./desk. You type 1 to add a name, 2 to list, 3 to kill a pid, 4 to quit. Each process is one struct: pid, name, alive. The table is an array. Functions take papers to those boxes.

Chapters you will touch

1 compile/run · 2 int/char · 3 printf/scanf · 4 if · 5 while menu · 6 name array · 7 functions · 8 & and * · 9 struct Process · 10 #include <stdio.h> (no -lpthread on this easy build).
