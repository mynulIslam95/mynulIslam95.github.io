C for OS · Chapter 6

Arrays — many boxes, one name

Index starts at 0. A string is a char array with a hidden '\0'. That is how "/myshm" exists. Walk with i < n. Do not walk off the end.

Jump to practice Ch5 loops

1. One name, many boxes

int a[4];
a[0] = 10;
a[1] = 20;
a[2] = 30;
a[3] = 40;
The rule

int a[4] is four int boxes in a row. The name is a. The index in square brackets selects which box. The first index is 0. The last index is 3, not 4. There is no a[4].

a[4] = 1 is out of range. It may compile. It is undefined. It can smash a mutex, a return address, a GPIO mapping. Off-by-one from Chapter 5 becomes a crash here.

2. Walk with for

int i;
for (i = 0; i < 4; i++) {
  a[i] = 0;          /* clear every box */
}

Test is i < 4, same as length. i <= 4 writes a[4]. Illegal.

The name a without [ ] is, in many expressions, a paper to the first box (Chapter 8). You do not need that yet. You need a[i]. For shm_open, you pass the array name of a string because that function wants a paper to the first character.

3. char arrays — strings

char name[] = "/myshm";

This is boxes: '/' 'm' 'y' 's' 'h' 'm' and one extra box '\0' (the terminator, value 0). printf("%s", name) prints until that 0. Functions like shm_open read until that 0.

Double quotes make this array. Single quotes make one char (Chapter 2). The leading slash in "/myshm" is POSIX (Chapter 10). The C fact is: it is a char array.

You may write char buf[64]; for a buffer you fill later. Clear it with a loop or with buf[0] = '\0'; if you only need empty.

4. Index is an int

a[i] — i is a number. a['A'] is a weird index (65). Do not. a[-1] is also out of range.

Copy: b = a[0]; copies one value. int b[4]; then you must loop to copy all, or later use memcpy. b = a does not copy four ints in this course’s C (arrays are not assigned that way). Trace one box at a time.

5. Tiny OS uses

  • Name string for shm_open("/myshm", ...)
  • A small buffer you read into
  • Sometimes a table of pids: pid_t kids[3];

Shared memory of many ints can be int *p from mmap, then p[0], p[1] — that is an array view of a pointer (Chapter 8). Same indexes. Same 0-based rule.
