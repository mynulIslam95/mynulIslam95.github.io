Two threads, one counter

File twins.c. Two workers, one struct Block with a mutex and a count. Each worker adds 1, one hundred thousand times, under the lock. Print the count. It must be 200000. Same process — not fork yet. That is P3.

Jump to steps P1 easy P3 hard

What done looks like

gcc twins.c -o twins -lpthread then ./twins prints 200000. If you drop the lock, the number is often smaller. That is the race. This project makes you feel why Chapter 8 said two papers, one box.
