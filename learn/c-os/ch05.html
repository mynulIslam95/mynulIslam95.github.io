Repeat — while and for

How many times. Off-by-one. A wait loop on a flag. Clear a buffer. Retry until wait returns. Trace i after each pass.

Jump to practice Ch4 choice

1. while — test, body, test again

int n = 3;
while (n > 0) {
  printf("%d\n", n);
  n = n - 1;
}
The rule

Check the test. If true, run the body, then check again. If false, skip the body and continue after the loop. If the test is false at the start, the body runs zero times.

Trace 
n=3  test 3>0 true  print 3  n=2
n=2  test true      print 2  n=1
n=1  test true      print 1  n=0
n=0  test false     stop
Output: 3  2  1  (each on a line)

If you never change n, the test stays true: infinite loop. The program does not reach return 0. In labs, while (1) is a server loop (xinetd/signal lab). You break it with a flag or by exiting.

2. for — same idea, packed

int i;
for (i = 0; i < 3; i++) {
  printf("%d\n", i);
}

Three pieces: start i = 0, test i < 3, step i++ after each body. This prints 0, 1, 2 — three times. Not 1,2,3. Not 0,1,2,3.

That is off-by-one: i <= 3 would run four times. Arrays (next chapter) have length 3 with indexes 0,1,2. So i < n is the habit, not i <= n.

3. Count how many times, on paper

Write a table: i (or n) before the body, what prints, i after the step. If you cannot fill the table, you are guessing. Boss skill is the table, not the word “loop.”

4. Wait loop on a flag

volatile int got = 0;
/* signal handler sets got = 1 */
while (got == 0) {
  /* wait. sometimes pause() lives here */
}
/* got is 1. continue */

This is Chapter 4’s test, repeated until false. The handler (Chapter 7) writes the box. volatile (Chapter 8) makes main really re-read it. The loop is this chapter.

while (1) { pause(); } sleeps until a signal. Still a loop. The body runs until you _exit or a flag breaks it.

5. Retry and waitpid

A parent may loop until a child is gone. A GPIO lab may loop toggling a pin. Same while/for. Sleep in the body if you must slow the pin. The C is still “body, then test again.”

OS door

Do not confuse a wait loop in C with the function wait(). wait() is one call that blocks inside the kernel. A while (got == 0) is your own repeat. Both “wait.” Different mechanisms. Name which one you mean.
