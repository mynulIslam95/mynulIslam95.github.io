C for OS · Project 3 · hard

Shared memory, two processes

File share.c. This is the whole C-for-OS ladder in one program. Two processes (not two threads). Named shared memory /myshm, mmap with MAP_SHARED, a mutex that both processes can take, fork, a SIGUSR1 handler that sets got only, then wait. After every C step is submitted right, the GitHub publish path opens. You publish your share.c repo — not this teaching site.

What done looks like

gcc share.c -o share -lpthread -lrt then ./share prints 1. Child adds one under the lock, then signals the parent. Parent’s handler sets a flag. Parent then waits and prints the count from the mapped bytes. If you forget MAP_SHARED or the process-shared mutex, the parent never sees the add.
