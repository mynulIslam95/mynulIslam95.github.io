Operating systems

Lesson 1. What the OS is actually doing. I am not selling a certificate. This is the picture I use at work and the one I learned in Information Engineering.

The machine is stupid without this

A laptop has a CPU, RAM and a disk. Those parts do not know Chrome, Word or WhatsApp. If you put electricity in and nothing else, you get a brick. The operating system is the first big program that wakes up, talks to the hardware, and then lets your apps run.

Windows is an OS. Linux is an OS. macOS is an OS. Android is an OS on a phone. Same job, different clothes.

Two rooms

Think of two rooms.

  • Kernel. Close to the metal. Memory, CPU time, disk, network card. You do not click around in here. If this breaks, the whole machine is gone.
  • User programs. Browser, editor, Teams, your Python script. They ask the kernel: give me RAM, open this file, send this packet.

That asking is a system call. You do not need the list of names yet. You only need the idea: apps are guests. The OS is the building.

A program is not a process

Chrome on disk is a program: a file. When you open it, the OS loads it into RAM and gives it a process. Two Chrome windows can be two processes from the same program. Task Manager and top show processes, not the installer.

When a process is stuck, you kill the process. You do not delete Chrome from disk. That is the difference, in one ticket.

Files are a story the OS tells you

On the disk there are blocks of bits. Folders, file names, C:\ and /home — that layout is the OS. Same USB stick looks different on Windows and Linux because each OS tells the story in its own way.

Why this matters on a helpdesk

At Mondia the ticket is almost never “the kernel crashed.” It is: laptop slow, disk full, app frozen, cannot print. Under that, it is still the OS: too many processes, no RAM left, a file lock, a driver. If you only know the app, you guess. If you see the OS, you have a place to look.

Check. You open Word twice. How many programs? How many processes?

Answer

One program on disk. Two processes in RAM, unless Word reuses one — the idea still holds: the file is the program, the running copies are processes.

Check. Chrome freezes. Do you uninstall Chrome, or end the process first?

Answer

End the process first. Uninstall is for when the program itself is broken. Freeze is usually the running copy.
