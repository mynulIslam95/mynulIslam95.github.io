Map · Floor 1 · OS2

Two workers, one shop

Same money box. Both add one. Sometimes one add is lost.

You need OS1 and C4. Two workers in one shop.

Story

A thread is a worker inside one shop. Two workers of the same shop share the money box. They see the same x.

That is cheap talk. That is also danger. Both add 1. x = x + 1 is three steps: read, add, write. Both can read 10. Both write 11. You wanted 12. One add is lost.

“A thread’s memory is protected so no other thread can touch it” sounds safe. It is false. Threads of one process share by design.

You do not need shared memory for two threads. They already live in one shop. You do not need twenty tickets. There is one box, not twenty violins.

Practice. Do two threads of one process share the heap?

Yes. Same shop, same boxes. Two processes after fork do not.

Practice. If both add 1 to x a thousand times, is x always 2000 with no lock?

No. A lost update can happen. You will need the key in OS3.

The same story in C

The worker function is what each thread runs. pthread_join waits until that worker finishes. If main returns without join, the whole shop closes and both workers die early. Compile with -pthread.

#include <pthread.h>

int x = 0;

void *worker(void *arg) {
  int i;
  for (i = 0; i < 1000; i++) {
    x = x + 1;
  }
  return NULL;
}

int main(void) {
  pthread_t t1, t2;
  pthread_create(&t1, NULL, worker, NULL);
  pthread_create(&t2, NULL, worker, NULL);
  pthread_join(t1, NULL);
  pthread_join(t2, NULL);
  return 0;
}

x is global so both workers see it. If x is local inside worker, each has a private box and there is no race. join waits. This still has no key — x may not be 2000.

Practice. Must x be global (or heap) for both workers to share it?

Yes. A local x inside worker sits on that thread’s own stack.

Practice. If main skips join, are you sure both workers finished?

No. When main returns, the process exits. Threads can die in the middle.

SS2018 Processes and Threads · true or false

“A thread’s address space is protected so no other thread can access it.”

Solution steps
  1. Read the sentence slowly. Threads of one process share the address space.
  2. Protected from threads of another process: different story. This sentence is about other threads — it is false.

SS2024 primes (short)

Ten workers search for a big prime. Are they threads or ten shops?

Solution steps
  1. If they share one result box, they are threads of one process.
  2. If each is a new program with its own memory, they are processes. The paper usually wants threads plus a lock on the result (OS3).
