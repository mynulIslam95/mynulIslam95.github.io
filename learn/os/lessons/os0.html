Map · Floor 1 · OS0

The building and the work

You can read this before C. There is no code on this page. Only a shop, a building, and the work inside.

Story

A laptop is a building with rooms: a brain (CPU), a table (RAM), a store room (disk). The rooms are empty. They do not know Chrome, Word, or WhatsApp.

If you only put power in, you get a dark shop. Nobody opens the door. Nobody puts boxes on the table.

The operating system is the first big program that wakes up. It is the building: lights, keys, who may use a room. Windows is one building. Linux is another. Same job, different paint.

Chrome and Word are not the building. They are work inside the shop. They ask the building: give me table space, open this file, send this letter.

Practice. Is Chrome the operating system?

No. Chrome is work inside the shop. Windows or Linux is the building. Chrome asks the building for memory and for the network.

Two rooms in the building

One room is close to the walls and the power. We call it the kernel. Memory, CPU time, disk, network card live here. You do not click around in this room. If this room falls, the whole shop is dark.

The other room is for guests: browser, editor, Teams, a small C program. Guests ask. They do not own the walls.

That asking is a system call. You do not need the list of names yet. Apps are guests. The OS is the building.

A recipe is not a running shop

Word on disk is a program: a file. A recipe in a book. When you open Word, the OS puts it on the table and it becomes a process: a running shop from that recipe.

You open Word twice. One recipe. Two running shops, unless Word reuses one. Task Manager and top show the running shops, not the book on the shelf.

When Word freezes, you stop the running shop. You do not throw the recipe in the bin. Uninstall is for when the recipe itself is broken.

Practice. Word freezes. Should you uninstall Word first?

No. End the process first. That is the running shop. Uninstall is later, if the program file itself is broken.

Practice. You open Word twice. Do you now have two programs on disk?

No. One program on disk. Two processes in RAM. The file is the recipe. The running copies are processes.

Names on the store room

On the disk there are only bits. Folders, file names, C:\ and /home are a story the OS tells you. The same USB stick can look different in Windows and in Linux. Each building tells the story in its own way.

At work the ticket is almost never “the kernel crashed.” It is: laptop slow, disk full, app frozen. Under that, it is still the building: too many running shops, no table space, a locked file. If you only know the app, you guess. If you see the OS, you have a place to look.
