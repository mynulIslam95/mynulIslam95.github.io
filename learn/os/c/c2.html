Boxes with names

A box with a name. A choice. A repeat. Then the same story in C.

Story

In the shop there is a box with a name. One box is called money. You put 10 inside.

A choice: if the box is 0, you close the shop. If it is not 0, you stay open.

A repeat: you add 1 to the box, again and again, three times. The box ends at 13.

The name of the box is not the money. The money is the number inside.

Practice. Is money a box that can hold a number?

Yes. In C that box is a variable. int money = 10; means: make a box for a whole number, put 10 in it.

Practice. If you write a new number in the box, does the old number stay there too?

No. A box holds one number at a time. The new number replaces the old one.

The same story in C

A whole number uses int. if is the choice. while is the repeat. printf shows what is inside.

#include <stdio.h>

int main(void) {
  int money = 10;
  int n = 0;
  while (n < 3) {
    money = money + 1;
    n = n + 1;
  }
  if (money == 0) {
    printf("closed\n");
  } else {
    printf("open, money=%d\n", money);
  }
  return 0;
}

money is the box. The while loop adds 1 three times. Then if asks: is the box empty?

Practice. After this program, is money still 10?

No. It started at 10. The loop added 1 three times. It is 13. The program prints open, money=13.

Practice. Is if (money == 0) the choice “is the shop empty?”

Yes. Two equal signs ask: is this equal to that? One equal sign would put a number in the box.
