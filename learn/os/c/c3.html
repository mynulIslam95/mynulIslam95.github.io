Map · Floor 0 · C3

Ask a helper

You send a job. The helper comes back with a number.

Story

You do not count every apple yourself. You ask a helper: “count these, come back with a number.”

You give the helper two numbers: how many boxes, how many apples in each. The helper returns the total.

You wait for the answer. Then you write it on the door.

Later, fork and waitpid are also helpers you call. First you must see a helper in a small story.

Practice. Does the helper give you back one answer?

Yes. That answer is the return value. In C, return total; sends it back to the caller.

Practice. Do you need to copy the helper’s whole job into every note?

No. You write the helper once. You call it when you need it. That is a function.

The same story in C

#include <stdio.h>

int count_apples(int boxes, int each) {
  return boxes * each;
}

int main(void) {
  int total = count_apples(4, 5);
  printf("apples=%d\n", total);
  return 0;
}

count_apples is the helper. 4 and 5 are what you give. return is the answer. main prints 20.

Practice. Does count_apples(4, 5) return 20?

Yes. Four boxes, five apples each. 4 × 5 = 20. total holds 20.

Practice. Is main the helper that counts apples?

No. main is still “start here.” It asks the helper, then prints.
