The note for the helper

You never wrote C. That is fine. This page is a shop story. Then a yes or no. Then the same story in four lines of C.

Story

You own a small shop. You cannot stand at the door all day. You write a note for a helper.

The note says: start here. Say “shop is open.” Then stop.

The helper cannot read your handwriting. A builder takes the note and builds a small tool. Now the helper can run the tool.

If you change the note, you must call the builder again. The old tool still does the old job until you build a new one.

Practice. You change the note. You do not call the builder. Does the helper now say the new words?

The helper runs the tool, not the paper. The paper is only for the builder. New words need a new tool.

Practice. Is “start here” the first thing in the note?

Every C note has a start. That start is called main. The helper always begins there.

The same story in C

The note is a file. We call it shop.c. The builder is a program called gcc. The tool the helper runs is ./shop.

#include <stdio.h>

int main(void) {
  printf("shop is open\n");
  return 0;
}

Line 1: bring the print toolkit. Line 3: start here. Line 4: say the words. Line 5: stop, all is well.

Practice. In this C, is main the “start here” of the note?

Yes. The helper always starts at main. printf is the line that speaks. return 0 means stop, no problem.

Practice. You only keep shop.c. You never run the builder. Can the helper already say “shop is open”?

No. shop.c is the note. The builder command is gcc shop.c -o shop. After that, the helper runs ./shop.

The word C is just the language of the note. You will use it again for locks and copies of the shop. First you must be able to start, speak, and stop.
