03 / HOW TO LEARN

A small step. Then another.

01 / READ

Understand the idea

Read the explanation and follow the example. Take your time with new words.

02 / PRACTISE

Try before you check

Write your answer first. Use a hint if you get stuck, then compare with the explanation.

03 / BUILD

Use what you learned

Work through a project. Change one part, run it again and explain what happened.
