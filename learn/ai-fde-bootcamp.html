SUBLESSON 1

Python Basics & Variables

Real Work Scenario
ধরো, তোমার Account এ €100 আছে। তুমি Penny তে €22 খরচ করলে। এখন কত টাকা বাকি আছে? মাথায় হিসাব করলে €78। এবার একই কাজ Python দিয়ে করি।

1. Python Code কোথায় Run করবো?

Computer এ Python 3 Install করা থাকলে একটা File বানাও: transactions.py। নিচের Code লিখে Save করো। Terminal এ python3 transactions.py দিয়ে Run করতে পারবে। Windows এ py transactions.py ব্যবহার করতে পারো।

print("My first transaction")

print() দিয়ে Screen এ কিছু দেখাই। এখানে Quotes এর ভিতরে লেখা Text টা Output হবে।

2. Variable মানে কী?

Variable কে একটা নাম মনে করো, যেটা দিয়ে কোনো Value ব্যবহার করতে পারি। যেমন balance নাম দিয়ে Account এর টাকা রাখবো।

balance = 100
expense = 22
remaining_balance = balance - expense

print(remaining_balance)
# Output: 78

এখানে = দিয়ে ডান পাশের Value বাম পাশের Variable এ Assign করছি। এটা দুইটা Value সমান কিনা Check করে না। balance - expense এর Result রাখছি remaining_balance এ।

Variable এর Name এ Space দেওয়া যায় না। remaining_balance ভালো Name। 2balance হবে না, কারণ Name Number দিয়ে শুরু করা যায় না। Python এ balance আর Balance আলাদা Name।

3. Transaction এর Data Types

store = "Penny"          # str: Text
item_count = 3           # int: Whole number
amount = 22.50          # float: Decimal number
payment_successful = True  # bool: True or False

print(type(store))
print(type(amount))
# Output:
# <class 'str'>
# <class 'float'>

Store এর Name Text, তাই Quotes ব্যবহার করেছি। Amount Number, তাই Quotes দিইনি। True আর False এর প্রথম Letter Capital হবে। type() দিয়ে Value এর Type দেখা যায়।

4. Balance Update করি

balance = 100
balance = balance - 22
print(balance)  # 78

balance = balance + 50
print(balance)  # 128

প্রথম Transaction এর পরে Balance €78। তারপর €50 Deposit করলে Balance €128। Python আগে ডান পাশের হিসাব করে, তারপর Result Assign করে। তাই একই Variable এর Value Update করা যায়।

5. Transaction Receipt দেখাই

store = "Penny"
amount = 22.50

print(f"Paid €{amount:.2f} at {store}")
# Output: Paid €22.50 at Penny

এটা একটা f-string। Text এর আগে f দিলে {} এর ভিতরে Variable বসানো যায়। :.2f দিয়ে Decimal এর পরে ২টা Digit দেখাচ্ছি। পরে String Operations এ এটা আরও Practice করবো।

6. User এর কাছ থেকে Input নিই

store = input("Store name: ")
amount_text = input("Amount in euros: ")
amount = float(amount_text)

print(f"Paid €{amount:.2f} at {store}")

input() সবসময় String Return করে। তুমি 22.50 লিখলেও সেটা প্রথমে Text থাকে। হিসাব করার আগে float() দিয়ে Number এ Convert করছি। Whole Number এর জন্য int() ব্যবহার করা যায়।

এই Example এ Amount হিসেবে 22.50 লিখবে, €22.50 বা 22,50 দিলে Conversion Error হবে। Error Handle করা পরে শিখবো।

7. Debugging: Type ভুল হলে কী হয়?

ধরো, API থেকে Amount এসেছে Text হিসেবে। Code Run করার আগে Output Predict করো। তারপর Run করে দেখো তোমার Prediction মিলেছে কিনা।

# Text আর Number এক না
print("22" + "3")  # 223
print(22 + 3)      # 25

# Variable ব্যবহার করার আগে Assign করতে হয়
expense = 22
print(expense)    # 22

# এর পরে লেখা অংশ Comment। Python এটা Execute করে না। নিজের Code বুঝিয়ে রাখতে Comment ব্যবহার করবো। এই Lesson এ সহজ হিসাবের জন্য Float ব্যবহার করছি। Real Payment System এ টাকার হিসাব করতে Integer Cents বা Decimal ব্যবহার করা ভালো, কারণ Float সব Decimal Value একদম Exact রাখতে পারে না।

Practice 1: Shopping Balance

তোমার Balance €150। Penny তে €22 আর Restaurant এ €18 খরচ করলে। তিনটা Variable বানিয়ে Total Expense আর Remaining Balance Calculate করো। তারপর নিচের মতো Receipt Print করো।

Total spent: €40.00
Remaining balance: €110.00

Try it yourself: আগে নিজের Python File এ Code লিখে Run করো।

Hint

Add the two expenses first. Subtract that total from the starting balance. Use an f-string with :.2f to format the results.

See Solution
balance = 150
penny_expense = 22
restaurant_expense = 18

total_spent = penny_expense + restaurant_expense
remaining_balance = balance - total_spent

print(f"Total spent: €{total_spent:.2f}")
print(f"Remaining balance: €{remaining_balance:.2f}")

Check Solution

তোমার Code এর Result এখানে দাও। এখানে Result Check হবে, Python Code Run হবে না।

Practice 2: Transaction Input

User এর কাছ থেকে Store Name আর Amount নাও। Amount কে Number এ Convert করো। Starting Balance €80। Store হিসেবে Lidl আর Amount হিসেবে 12.50 দিয়ে Run করলে নিচের Output আসতে হবে।

Paid €12.50 at Lidl
Remaining balance: €67.50
Hint

Use input() twice. Convert the amount with float() before subtracting it from the balance.

See Solution
balance = 80
store = input("Store name: ")
amount = float(input("Amount in euros: "))

remaining_balance = balance - amount

print(f"Paid €{amount:.2f} at {store}")
print(f"Remaining balance: €{remaining_balance:.2f}")

Check Solution

Lidl Example এর দুইটা Output Line Paste করো। Input Prompt দিতে হবে না। এখানে শুধু Output Check হবে।
