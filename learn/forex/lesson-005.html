01 / Pip: price movement, not money

Pip হলো Currency Pair-এর Price Movement Measure করার Unit। EUR/USD 1.1000 থেকে 1.1001 গেলে 1 Pip Move করেছে। কিন্তু 1 Pip = $1 বলা ভুল, কারণ Dollar Value নির্ভর করে Position Size আর Quote Currency-এর ওপর।

Original visual · standard 4-decimal pair
1.1000Before · EUR/USD
1.1001After · EUR/USD
(1.1001 − 1.1000) ÷ 0.0001 = +1 pip

02 / Which decimal place is one pip?

EUR/USD, GBP/USD, AUD/USD-এর মতো অনেক Pair-এ 1 Pip = 0.0001। JPY Quote Currency হলে, যেমন USD/JPY বা EUR/JPY, সাধারণ Convention হলো 0.01।

Original precision diagram
1.2345Fourth decimal: 5 = pip digit
150.25Second decimal: 5 = pip digit
Non-JPY example: 1 pip = 0.0001
JPY example: 1 pip = 0.01

This is a widely used convention, not a rule for every currency or non-FX instrument. Check each instrument's contract specification.

03 / Pipette: the tiny extra decimal

Broker EUR/USD 1.23456 দেখালে Last Digit হলো সাধারণত Pipette। 1 Pipette = 0.1 Pip। USD/JPY 150.257 দেখালে Third Decimal Digit সাধারণত Pipette।

Original diagram · fractional pip
1.23456EUR/USD · 5th decimal = pipette
150.257USD/JPY · 3rd decimal = pipette
10 pipettes = 1 pip

EUR/USD 1.23456 → 1.23459 = 3 pipettes = 0.3 pip. USD/JPY 150.257 → 150.262 = 5 pipettes = 0.5 pip.

04 / Pips can be positive or negative

Price Up মানেই Profit না। Long হলে Up Move Favorable হতে পারে, Short হলে Down Move Favorable হতে পারে।

Direction matrix
LONG ↑Favorable if exit price exceeds entry
LONG ↓Unfavorable
SHORT ↓Favorable if exit price is lower
SHORT ↑Unfavorable

Actual results depend on bid/ask execution and costs. “Favorable” refers to direction only.

05 / Count pips on EUR/USD

Suppose EUR/USD moves from 1.08420 to 1.08675.

1.08675 − 1.08420 = 0.00255
0.00255 ÷ 0.0001 = 25.5 pips

Last Fifth Decimal-টা Ignore করবে না। 25.5 Pips মানে 25 Pips + 5 Pipettes।

This measures movement between two specified prices, not necessarily realized trade profit.

06 / Count pips on USD/JPY

Suppose USD/JPY moves from 150.250 to 149.875.

149.875 − 150.250 = −0.375 JPY per USD
−0.375 ÷ 0.01 = −37.5 pips

JPY Pair-এর Pip Size 0.01। ভুল করে 0.0001 দিয়ে Divide করলে 100 গুণ ভুল Answer পাবে।

07 / Pip value: the key professional formula

এবার সবচেয়ে গুরুত্বপূর্ণ Part। Pip Value হলো 1 Pip Price Move করলে তোমার Position-এর Profit বা Loss Quote Currency-তে কত Change হবে।

Core formula · for linear spot-style currency exposure
Pip value in quote currency = base units × pip size

Q = position size in base-currency units. Pip size = quote-currency units per base-currency unit for one pip.

Q = 10,000 EUR; pip size = 0.0001 USD/EUR
10,000 × 0.0001 = $1 per pip

Pip Value হলো Position Size-এর Function। Broker-এর Contract Multiplier, Currency Conversion আর Product Type Check করা জরুরি।

09 / Why USD/JPY has a different pip value

USD/JPY-এর Quote Currency হলো JPY। তাই Pip Value প্রথমে Yen-এ Calculate হবে। ধরো 100,000 USD Position আর USD/JPY = 150.00।

Worked example · yen to dollars
100,000 USD × 0.01 JPY/USD = ¥1,000 per pip
¥1,000 ÷ 150.00 JPY/USD ≈ $6.67 per pip

For a USD account, the converted pip value changes as USD/JPY changes. For a JPY account, it remains ¥1,000 per pip for the same base units and contract terms.

Uses a hypothetical single conversion rate and excludes currency conversion fees or bid/ask differences.

10 / USD/CHF: a third example

Assume USD/CHF = 0.9000 and position size = 100,000 USD. The quote currency is CHF.

100,000 × 0.0001 = CHF 10 per pip
CHF 10 ÷ 0.9000 CHF/USD ≈ $11.11 per pip

USD/CHF-এ 1 Standard Lot-এর Pip Value $10 না। Quote Currency CHF হওয়ায় Dollar Conversion করতে হয়।

11 / Cross pair: EUR/GBP and a USD account

EUR/GBP-এ Quote Currency হলো GBP। USD Account হলে GBP Pip Value-কে USD-তে Convert করবে। ধরো EUR/GBP Position = 10,000 EUR, GBP/USD = 1.2500।

10,000 × 0.0001 = £1 per pip
£1 × 1.2500 USD/GBP = $1.25 per pip

For a EUR-denominated account, the conversion would instead use EUR/GBP: if EUR/GBP = 0.8800, then £1 ÷ 0.8800 GBP/EUR ≈ €1.1364 per pip.

Cross-rates are hypothetical synchronized reference rates. Actual conversion rates and fees may differ.

12 / The account currency changes the result

একই EUR/USD Trade দুই Trader করে। একজনের Account USD, আরেকজনের Account EUR। Quote-Currency Pip Value Same হলেও Account Balance-এ Displayed Value আলাদা হতে পারে।

10,000 EUR/USD position · hypothetical EUR/USD 1.1000
$1.00USD account · 1 pip
≈ €0.91EUR account · 1 pip
$1 ÷ 1.1000 USD/EUR ≈ €0.9091

The conversion rate may change over the holding period. A broker may convert realized P&L at its own rate.

13 / Why pip value is not always constant

EUR/USD Position-এর Pip Value USD Quote Currency-তে Constant থাকে যদি Base Units Same থাকে। কিন্তু EUR Account-এ USD থেকে EUR Convert করলে Value Change হয়। USD/JPY-এর USD Pip Value-ও Exchange Rate-এর সঙ্গে Change হয়।

Compare USD/JPY at two rates
$10.00¥1,000 ÷ 100 JPY/USD
$6.67¥1,000 ÷ 150 JPY/USD

Same 100,000 USD position, same ¥1,000 per pip in JPY, but different USD equivalents.

14 / Position size from a risk budget

ধরো তুমি একটা Demo Trade-এ Maximum $20 Loss Budget করেছো। Stop Distance 25 Pips। EUR/USD-এ USD Account হলে 1 Pip-এর Maximum Value কত হতে পারে?

Allowed $/pip = $20 ÷ 25 = $0.80 per pip
Base units = $0.80 ÷ 0.0001 = 8,000 EUR

At 8,000 EUR, a 25-pip adverse movement represents approximately $20 in price P&L before spread, slippage, commissions and gaps. A stop order does not guarantee a maximum loss.

Risk Management-এ Pip Value কেন Important বুঝতে পারছো? Same Stop Distance হলেও Position Size Change করলে Dollar Risk Change হয়।

15 / Spread costs in pip value

Suppose EUR/USD bid = 1.10000 and ask = 1.10015. The spread is 1.5 pips. You trade 20,000 EUR.

Spread = (1.10015 − 1.10000) ÷ 0.0001 = 1.5 pips
Pip value = 20,000 × 0.0001 = $2/pip
Immediate round-trip price difference = 1.5 × $2 = $3

Assumes both quotes are executable and unchanged. Do not subtract this spread again if your P&L formula already uses entry ask and exit bid.

16 / Price movement is not percentage return

20 Pip Move শুনে মনে হতে পারে 20% Profit। এটা সম্পূর্ণ ভুল। Pip হলো Price Unit, Percentage Return নয়।

EUR/USD: 1.1000 → 1.1020 = +20 pips
Relative price change ≈ (0.0020 ÷ 1.1000) × 100 = 0.1818%

Percentage return on your deposited margin can be much larger or smaller because leverage and position sizing change exposure relative to capital. That does not make the underlying currency movement larger.

18 / Professional traps and edge cases

  1. Wrong quote currency: USD/CHF-এর CHF 10 per pip-কে $10 ধরে নেওয়া।
  2. Wrong JPY decimal: USD/JPY-তে 0.0001 ব্যবহার করা।
  3. Wrong lot assumption: Every broker's contract size and minimum order differ.
  4. Double-counted spread: Entry ask and exit bid already embed the price-side difference.
  5. Conversion ignored: Account currency may differ from quote currency.
  6. Stop-loss guarantee assumed: Gaps and slippage can increase realized loss.
  7. Nonlinear products: Options and certain derivatives do not follow this simple linear pip-value model.
  8. Rounded display: Fractional pips and broker rounding can affect displayed values.

19 / Practice lab: calculate before opening answers

A. EUR/USD rises from 1.08235 to 1.08380. How many pips?

Answer

(1.08380 − 1.08235) ÷ 0.0001 = 14.5 pips.

B. USD/JPY falls from 151.240 to 150.865. How many pips?

Answer

(150.865 − 151.240) ÷ 0.01 = −37.5 pips.

C. What is EUR/USD pip value for 25,000 EUR?

Answer

25,000 × 0.0001 = $2.50 per pip.

D. USD/JPY 150.00, 30,000 USD position. Pip value in JPY and approximate USD?

Answer

30,000 × 0.01 = ¥300/pip; ¥300 ÷ 150 = $2/pip.

E. EUR/GBP 10,000 EUR, GBP/USD 1.2500. Pip value in USD?

Answer

10,000 × 0.0001 = £1; £1 × 1.2500 = $1.25 per pip.

F. Risk budget $15, stop distance 30 pips, EUR/USD USD account. Maximum idealized position size before costs?

Answer

$15 ÷ 30 = $0.50 per pip; $0.50 ÷ 0.0001 = 5,000 EUR. Real stop losses may slip and exceed the budget.

20 / Mastery check

নিজের ভাষায় Explain করতে পারলে Lesson Complete Mark করো।

1. What is the difference between a pip and a pipette?

A pipette is one-tenth of a pip. Common EUR/USD examples use 0.0001 per pip and 0.00001 per pipette.

2. Why is USD/JPY pip size different from EUR/USD?

JPY-quoted FX pairs conventionally use 0.01 JPY per pip, while EUR/USD conventionally uses 0.0001 USD per EUR per pip.

3. What is the general quote-currency pip-value formula?

Base-currency units × pip size, for a linear currency exposure.

4. Why isn't one pip always $10?

Position size and quote currency differ; account-currency conversion may also be required.

5. Why might pip value change even when lot size is constant?

Its value in the account currency changes when exchange-rate conversion changes, even if its value in the pair's quote currency is fixed.

6. How can you calculate an approximate position size from a stop distance?

Risk budget ÷ stop distance in pips = allowed account-currency value per pip. Convert that into base units using the correct quote/account conversion and pip size, then allow for fees and slippage.

Professional Forex case study · worked answer

Pip value with account-currency conversion

Worked calculation: For 10,000 EUR/USD, one pip = 10,000 × 0.0001 = USD 1. For 10,000 USD/JPY, one pip = 10,000 × 0.01 = JPY 100; at USD/JPY 150, that is about USD 0.67.

Professional limitation: JPY pairs commonly use 0.01 as one pip. Conversion rate and account currency affect realized pip value.
