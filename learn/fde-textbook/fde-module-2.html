Read a paginated API response with Python

Your teammate needs to inspect one product without downloading the whole catalogue. In a uv project, run uv add requests, save this as read_catalogue.py and run uv run python read_catalogue.py.

import requests

url = "https://dummyjson.com/products"
try:
    response = requests.get(url, params={"limit": 1, "skip": 5}, timeout=5)
    response.raise_for_status()
    data = response.json()
except requests.RequestException as error:
    raise SystemExit(f"Could not read the catalogue: {error}")

print("HTTP status:", response.status_code)
for product in data["products"]:
    print(product["id"], product["title"])

On success, expect HTTP status: 200 and one product row. The product can change as the demo catalogue changes. params encodes the query string. skip=5 skips five records and limit=1 asks for one. Try skip=0 and predict which row changes.

Check the HTTP status before using the JSON. raise_for_status() raises on 4xx and 5xx responses. A timeout limits how long Requests waits during connection or while receiving data. It does not impose a deadline on the entire download. For a large collection, request one page at a time and process it before fetching the next one. Wrapping a fully downloaded JSON list in a generator still leaves that list in memory.
