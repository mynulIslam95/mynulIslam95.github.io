Evaluation concepts

  • Qualification Accuracy-এর denominator সব Labeled Cases। Easy Examples দিয়ে শুধু ভালো Result দেখালে Reliability বোঝা যায় না।
  • Citation Support Human Labels বা Carefully Reviewed Rubric দিয়ে যাচাই করো। LLM Judge-এর Score-এর সাথে Human Review Sample রাখো।
  • Unauthorized Block Rate-এর denominator Unauthorized Attempts। Zero Unauthorized Cases হলে Metric None/Not measured হবে।
  • Cost per Report-এ Actual Model Usage, Relevant Service Cost আর Pricing Date লিখো। Synthetic Demo Numbers-কে Actual Results হিসেবে Publish করবে না।
  • Availability, Latency Target আর Resource Budget Pilot-এর আগে define করো। Alert Trigger হলে কোন Investigation Command চালাবে Runbook-এ রাখো।

Worked evaluation lab

lab_7.py

from statistics import mean

def summarize(runs: list[dict]) -> dict:
    if not runs:
        raise ValueError("Evaluation set must not be empty")
    correct = sum(run["expected"] == run["actual"] for run in runs)
    unauthorized = [run for run in runs if not run["authorized"]]
    blocked = sum(not run["executed"] for run in unauthorized)
    return {
        "cases": len(runs),
        "qualification_accuracy": correct / len(runs),
        "unauthorized_block_rate": blocked / len(unauthorized) if unauthorized else None,
        "mean_latency_ms": mean(run["latency_ms"] for run in runs),
        "mean_cost_usd": mean(run["cost_usd"] for run in runs),
    }

if __name__ == "__main__":
    runs = [
        {"expected": "fit", "actual": "fit", "authorized": True,
         "executed": True, "latency_ms": 200, "cost_usd": 0.01},
        {"expected": "insufficient_evidence", "actual": "fit", "authorized": False,
         "executed": False, "latency_ms": 100, "cost_usd": 0.005},
    ]
    result = summarize(runs)
    assert result["qualification_accuracy"] == 0.5
    assert result["unauthorized_block_rate"] == 1.0
    print(result)

SLOs, capacity & operational readiness

এই Step-এর System Design Review-এ নিচের Decisions লিখবো আর Evidence দিয়ে ব্যাখ্যা করবো।

  1. Pilot-এর আগে Measurable Targets লেখো — Successful Job Rate, Queue Waiting Time, End-to-end p95 Latency, Cost per Report আর Unauthorized Action Rate। এগুলো Target, Measured Result আলাদা হবে।
  2. Capacity Estimate-এ Peak Reports/minute × Average Service Time দিয়ে Rough In-flight Work বের করো। উদাহরণ 60 Reports/minute × 20 seconds ≈ 20 in-flight Reports। Arrival Burst, Provider Limits ও Load Test দিয়ে Estimate refine করো।
  3. Tenant Quotas, Maximum Job Runtime, Bounded Queue ও Admission Control রাখো। Overload-এ কোন Requests Reject/Defer হবে আর UI কী দেখাবে define করো।
  4. Deployment Review-এ Backup Restore, Recovery Time Target, Data Loss Tolerance, Rollback, Alerts ও Incident Ownership record করো।
