Skills, Projects & Hiring Strategy

0.1 তোমার Starting Point

Full-time Software Job নেই, কিন্তু Working-student Experience আছে। CV তে সত্যিকারের Automation, Troubleshooting আর Stakeholder Work দেখাবে। IT Operations কে Software Development বলে লিখবে না।

Targets: New-grad FDE • Graduate SWE • SDE I • Associate SWE • Early-career SWE • Junior Applied AI Engineer

0.2 Hiring Reality

Degree Completion Date, Graduation Window, Work Authorization আর Team Language আগে Check করবে। US Role এর জন্য US Work Authorization আর Germany Role এর জন্য Germany Work Rights আলাদাভাবে Confirm করতে হবে।

Certificates Supporting Evidence। Coding, Debugging আর Independent Implementation হবে Main Evidence।

0.3 Skills যা হাতে দেখাতে হবে

Python/OOP, SQL/Transactions, Git/PRs, DSA, OS/Networking, HTTP/APIs, Tests, Security, Docker/AWS, Logs আর Debugging। AI Track এ RAG, Evaluation, Structured Outputs আর Safe Tool Use।

প্রতিটা Project এ একটা Bug Reproduce → Root Cause → Fix → Regression Test এর Story রাখবে।

0.4 Project 1: Customer Operations Platform

Customers, Orders আর Tickets Manage করার Fullstack App। FastAPI, PostgreSQL, React/TypeScript, Docker আর AWS ব্যবহার করবে।

Build checklist: Login/RBAC • Tenant Isolation • CRUD/Search/Pagination • Transaction-safe Updates • Webhook • Background Jobs/Retry • Duplicate-event Protection • Tests/CI • Health Checks/Rollback • Load Test।

0.5 Project 2: Enterprise Knowledge & Action Assistant

Company Documents থেকে Permission অনুযায়ী Cited Answers দেবে। Tool দিয়ে Ticket Draft করবে, Human Approval এর পরে Sandbox Ticket Create করবে।

Build checklist: Ingestion • RAG • No-answer Behaviour • Citations • Validated Tool Arguments • Approval/Audit Trail • Evaluation Dataset • Prompt-injection Tests • Cost/Latency। Junior AI Roles এর জন্য ছোট Ticket Classification Baseline যোগ করবে: Train/Test Split, Leakage Checks, Precision/Recall/F1 আর Error Analysis।

0.6 Portfolio Evidence Pack

দুইটা Repository, Working Demo, ছোট Video, Architecture Diagram, Setup Instructions, Automated Tests, CI আর Meaningful PRs রাখবে। Real User Feedback পেলে Document করবে।

Performance বা Evaluation Numbers বানাবে না। কী Dataset, Load আর Environment এ Measure করেছ লিখবে। একই Projects, Software Role এ প্রথমটা আগে, AI Role এ দ্বিতীয়টা আগে দেখাবে।

0.7 দুইটা Certification

প্রথমে AWS Certified Developer – Associate, Project Deploy করার পরে। তারপর Databricks Certified Generative AI Engineer Associate, Databricks দিয়ে AI Project এর একটি বাস্তব Implementation/Evaluation Path তৈরি করার পরে।

Research Snapshot: AWS Listed Fee $150, Databricks $200। Taxes/Local Pricing আলাদা হতে পারে। Databricks Relevant Hands-on Experience Recommend করে। Exam Version আর Fees Booking এর আগে Official Page এ Check করবে। Certificates শেষ হওয়ার অপেক্ষায় Applications বন্ধ রাখবে না।

0.8 Interview Preparation

DSA Pattern Practice Python Data Structures শেখার পর থেকেই চলবে। 75টা Core + 25টা Optional Problem দিয়ে শুরু, Weak Patterns অনুযায়ী Expand করবে। SQL, Debugging, Junior System Design আর Project Deep Dive Practice করবে।

Behavioral Stories: Ownership, Failure, Conflict, Feedback, Ambiguity, Customer Communication। STAR Notes নিজের Working-student Experience আর Project Decisions থেকে লিখবে।

0.9 Job Security নিয়ে বাস্তব কথা

কোনো Company Layoff-proof না। Hiring আর Layoffs একই Company তে হতে পারে। Revenue-generating Product, Approved Headcount, বাস্তব Customer Usage আর ভালো Junior Mentorship খুঁজবে।

Manager Questions: Role নতুন নাকি Replacement? Budget Approved? গত বছরে Team কীভাবে বদলেছে? Mentor কে? প্রথম 6 মাসের Success Criteria কী? Startup হলে Runway সম্পর্কে কী Share করতে পারবেন?

0.10 তোমার Execution Order

Foundation → ছোট Projects → Deployed Backend/Fullstack App → AI Assistant → Interview Mocks। AI Assistant দিয়ে কাজ করলেও Code বুঝতে, Test করতে আর Debug করতে হবে।

8টা Practice Milestone + 2টা Capstone Roadmap এ আছে। কিছু কাজ Reuse হবে। CV তে প্রধান দুইটা Capstone দেখাবে। নতুন Career Blueprint Orientation Module, অতিরিক্ত Project না।
