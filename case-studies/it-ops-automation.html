it-ops-automation

Problem

A fictional office, Northfield, needs one Windows workstation, one Ubuntu host, repeatable support, a backup that has been restored, and identity that is more than a local laptop account.

What is in the repo

  • PowerShell inventory to CSV (no passwords, no personal files) and a Bash health check with fail exit codes.
  • Five tickets with symptoms, checks, cause, fix and verification: DNS, stopped spooler, share permissions, low disk, locked account.
  • Backup and restore of a synthetic share; sample restore transcript.
  • Ansible playbook: packages, office group, share mode 2770, UFW SSH, health script.
  • Active Directory script and notes for forest northfield.lab, OU, group, three users, GPO. Needs a Windows Server evaluation VM.
  • Entra, Microsoft 365 and Intune commands. They need a tenant. Evidence goes in evidence/entra/ when run.

How to check it

On Ubuntu or WSL2: ./tests/test_scripts.sh runs health, backup and restore. On Windows: .\scripts\Get-DeviceInventory.ps1. Compare your output to evidence/. Read each runbook and confirm the verification command is there. If AD or Entra evidence folders are empty, that work is still in the scripts. Run it on the VM or tenant and add the files.
