azure-infra-foundation

View repository

Problem

Northfield needs a small Azure environment that can be described in Git: network separation, locked-down management, storage, monitoring and a cleanup path. Deploy is optional and costs money.

What is in the repo

  • Terraform: resource group, VNet module, subnet, NSG (443 from office CIDR, deny SSH from Internet), storage, Log Analytics.
  • GitHub Actions: terraform fmt, init -backend=false, validate.
  • RBAC table, cost checklist, Monitor diagnostic settings, blob restore, remote-state backend example, destroy steps.

terraform validate is not a successful deploy. terraform plan needs Azure credentials. The README table states what is files-only and what needs apply.

How to check it

Run the three Terraform commands in terraform/. Open the Actions tab after the first push. If evidence/ has no apply or cleanup files, the subscription apply has not been run yet — do not treat the lab as deployed.
